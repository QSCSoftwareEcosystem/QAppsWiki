# K-Inverse-K (KIK)

> **Imported by `qappswiki import-zoo qemzoo`** from the [QEM Zoo](https://qemzoo.com/technique.html?id=kik) (`id: kik`, catalog: techniques, category: mitigation). Public domain (The Unlicense); cited as the QEM Zoo (qemzoo.com), public domain (The Unlicense). This is a `needs-verification` page — confirm against the references below.

## Summary

Reconstructs and divides out the noise channel using pulse-based inverse evolutions rather than extrapolating it away. Writing K for the noisy circuit and K_I for a noisy inverse evolution generated by reversing and negating the drive, the ideal evolution satisfies $U \approx K(K_I K)^{-1/2}$ to first order in the Magnus expansion. The inverse square root is expanded polynomially, so the circuits $K(K_I K)^m$ are executed and combined with coefficients fixed analytically by a single measured noise-strength parameter. The method handles moderate-to-strong, time-dependent and spatially correlated noise, and integrates with randomized compiling to cover coherent errors.

(source: raw/qem-zoo.md)

## Properties

| Property | Value |
|---|---|
| Bias | Suppressed exponentially in the expansion order below a noise threshold; residual bias from truncating the Magnus expansion at first order |
| Sampling overhead | Low; number of circuits is independent of system size |
| Noise model required | None; no tomography or machine learning required |
| Applicability | General-purpose; handles moderate-to-strong noise, time-dependent noise, and spatially correlated errors |
