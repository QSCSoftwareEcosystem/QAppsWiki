## Description

Seven-qudit MDS error-detecting code defined for Galois-qudit dimension $q=3$  ([doi:10.1109/TIT.2002.800469](https://doi.org/10.1109/TIT.2002.800469)) and $q \geq 7$  ([doi:10.1109/TIT.2002.800469](https://doi.org/10.1109/TIT.2002.800469)) ([arXiv:quant-ph/0508070](https://arxiv.org/abs/quant-ph/0508070)).
This code cannot exist for qubits ($q=2$).
