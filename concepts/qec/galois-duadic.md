## Description

True Galois-qudit stabilizer code constructed from $q$-ary duadic codes via the Hermitian construction or the Galois-qudit CSS construction.
Large subclasses of quantum duadic codes are degenerate  ([arXiv:0812.5104](https://arxiv.org/abs/0812.5104)).

Quantum construction X yields an infinite family of quantum duadic codes with favorable parameters  ([arXiv:2211.00891](https://arxiv.org/abs/2211.00891)).
