## Description

Family of self-dual CSS codes, one for each $j\geq 3$, whose qubits are the points of an elliptic quadric in $\mathbb{F}_2^{2j}$.
Both the $X$- and $Z$-type stabilizer generators are the codewords of the order-$(j-2)$ RM code punctured to that quadric.
The qubit permutation automorphism group contains the symplectic group $Sp(2j,2)$ acting in its minimal-degree faithful permutation representation.

Fix an elliptic quadratic form $Q_0$ on $V=\mathbb{F}_2^{2j}$, i.e., one of Arf invariant one, and take its zero set $Z(Q_0)=Q_0^{-1}(0)$ as the qubits.
Both classical codes are the restrictions to $Z(Q_0)$ of all Boolean functions of algebraic degree at most $j-2$,
\begin{align}
  C_X=C_Z=\text{RM}(j-2,2j)\big|_{Z(Q_0)}~,
\end{align}
yielding the family
\begin{align}
  QT_j=⟦2^{2j-1}-2^{j-1},\,k_j,\,2^{j-1}⟧~,\qquad k_j=14,48,166,584,2092,\ldots
\end{align}
for $j=3,4,5,6,7,\ldots$, with $k_j=V_{j-1}-V_{j-2}$ in terms of the alternating binomial sums $V_r=S_r-S_{r-2}+S_{r-4}-\cdots$ and $S_a=\sum_{i\leq a}\binom{2j}{i}$.
The first two members are $QT_3=⟦28,14,4⟧$ and $QT_4=⟦120,48,8⟧$.

Writing $B$ for the polar form of $Q_0$, the map $a\mapsto Q_0+B(a,\cdot)$ identifies the qubits with one Arf class of quadratic forms on $\mathbb{F}_2^{2j}$.
The symplectic group permutes that class, acting affinely on the quadric coordinates, and the class is the smallest set on which $Sp(2j,2)$ can act faithfully  ([doi:10.1515/crll.1941.183.148](https://doi.org/10.1515/crll.1941.183.148), [doi:10.1007/BF02761072](https://doi.org/10.1007/BF02761072)).
For $j=3$, the classical code is the $[28,7,12]$ code whose automorphism group is $Sp(6,2)$  ([doi:10.3336/gm.49.2.01](https://doi.org/10.3336/gm.49.2.01)).

## Protection

The distance is $d_j=2^{j-1}\approx\sqrt{n_j/2}$, verified for $j\leq 6$ and holding in general modulo a degree-sharpness condition on the associated Koszul complex  ([arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).
A lower bound follows by multiplying a Boolean function $g$ of degree at most $j-1$ by $1+Q_0$.
This multiplication turns restriction weights on the quadric into ambient weights.
The product lies in $\text{RM}(j+1,2j)$, whose minimum distance is $2^{j-1}$.
The same argument applied one layer down shows that every nonidentity stabilizer element has weight at least $2^j$, so the codes are pure.
Quadric tower codes saturate an automorphism-group bound on permutation degree  ([arXiv:2604.15111](https://arxiv.org/abs/2604.15111)).
Self-orthogonality and doubly-evenness of the classical code both follow from the Ax-Katz theorem applied to point counts on the quadric.

## Rate

The rate $k_j/n_j$ takes the values $0.50, 0.40, 0.335, 0.29,\ldots$ and behaves as $\Theta(1/\sqrt{j})=\Theta(1/\sqrt{\log n})$  ([arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).

## Transversal gates

- CNOT gate between two blocks because the code is CSS, transversal Hadamard because the code is self-dual, and transversal $S$ because the underlying classical code is doubly even  ([arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).
- Qubit permutations realizing $Sp(2j,2)$ in its minimal-degree action, generated by the linear transvections stabilizing $Q_0$ together with affine transvections  ([arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).
- Fold-transversal gates for every involution of the permutation action, since the underlying classical code is self-orthogonal  ([arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).
- Two-fold transversal gates generate the full logical Clifford group for the first two members, namely $Sp(28,2)$ for $QT_3=⟦28,14,4⟧$ and $Sp(96,2)$ for $QT_4=⟦120,48,8⟧$  ([arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).
