## Description

Self-dual doubly-even CSS code that is the 4.8.8 color code on the smallest torus, *twisted* in that one boundary identification is shifted by half a period  ([arXiv:2112.03785](https://arxiv.org/abs/2112.03785)).
Equivalently, it is the concatenated symplectic double of the $⟦4,2,2⟧$ code, i.e., its inner $⟦8,4,2⟧$ symplectic double with each $ZX$-dual pair of qubits encoded into an outer $⟦4,2,2⟧$ block  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).
Automorphisms of the $⟦4,2,2⟧$ seed lift through this structure to logical gates realized by qubit permutations  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).

Fattening each vertex of the $2\times 2$ square lattice into a square yields four square faces and four octagonal faces, shown in \ref{figure:16-4-4-488}.
The octagons are two-colored in checkerboard fashion.
This gives eight faces on 16 qubits and 24 edges.
Gluing the shifted pair of boundaries straight instead yields a different code.



The seed is the non-CSS presentation $\langle XZZX, ZXXZ\rangle$ of the $⟦4,2,2⟧$ code, whose symplectic double is an $⟦8,4,2⟧$ CSS code on two copies of its four qubits  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).
Qubit $i$ of the first copy and qubit $i$ of the second are exchanged by the $ZX$ duality of the double.
Each such pair is encoded as the two logical qubits of one $⟦4,2,2⟧$ block with logical operators $\overline{X}_1=XXII$, $\overline{Z}_1=ZIZI$, $\overline{X}_2=XIXI$, and $\overline{Z}_2=ZZII$  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).
The code is isomorphic to the $L=2$ many-hypercubes (MHC) code built from the $⟦4,2,2⟧$ code  ([arXiv:2403.16054](https://arxiv.org/abs/2403.16054), [arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).
Equivalently, it is two copies of the $⟦4,2,2⟧$ code concatenated with the $⟦4,2,2⟧$ code  ([arXiv:2008.05051](https://arxiv.org/abs/2008.05051)).

A stabilizer tableau for the code is  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753))

## Protection

Detects errors on up to 3 qubits and corrects errors on 1 qubit.

## Encoders

- A fault-tolerant, bare-ancilla state-preparation procedure for the logical $|\overline{0}\rangle$ and $|\overline{+}\rangle$ states is given in  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).

## Transversal gates

- SWAP-transversal gates lifted from automorphisms of the seed $⟦4,2,2⟧$ code, together with the $ZX$-duality gates $\overline{H}_\tau$ and $\overline{S}_\tau$ inherited from the symplectic double, give $216$ unique logical gates  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).
Adding a global logical phase gate gives the group $(A_8\times A_8)\rtimes(C_2\times C_2)\subset Sp(8,2)$  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).
Only one of the $20$ $ZX$-dualities admits a phase-type gate, and the permissible qubit permutations $C_2\times S_4$ act non-faithfully with image $D_6$. Together with all two-qubit entangling gates, they generate the logical orthogonal subgroup $\Omega^{+}(8,2)$  ([arXiv:2202.06647](https://arxiv.org/abs/2202.06647)).
Adjoining a targeted logical $S$ on a single logical qubit yields all of $Sp(8,2)$  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753), [arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).

## General gates

- Any logical Clifford circuit on the four logical qubits can be compiled using the SWAP-transversal gateset together with at most a small number of logical phase-gate injections  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)). The injections are performed via state teleportation  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).

## Fault tolerance

- Single-shot distance-three fault-tolerant error correction with 12 nonadaptive stabilizer measurements in six rounds, or with eight or ten adaptively chosen measurements in four rounds  ([arXiv:2008.05051](https://arxiv.org/abs/2008.05051)).
- The transversal phase gate on the inner $⟦8,4,2⟧$ symplectic double code requires performing logical global phase gates on each $⟦4,2,2⟧$ block to remain SWAP-transversal on the concatenated code  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)). This can be implemented fault-tolerantly but requires two-qubit gates  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).
- An automorphism gate that swaps logical qubits between different $⟦4,2,2⟧$ blocks requires additional $⟦4,2,2⟧$ ancilla blocks to implement fault-tolerantly  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753)).

## Realizations

- Neutral atom arrays: state initialization of the $⟦16,4,4⟧$ twisted color code on a device by Infleqtion  ([arXiv:2509.13247](https://arxiv.org/abs/2509.13247)).
