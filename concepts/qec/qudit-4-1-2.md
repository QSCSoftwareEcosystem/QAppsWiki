## Description

A $⟦4,1,2⟧_5$ pure prime-qudit CSS code on four ququints, i.e., five-dimensional qudits, that is the smallest known non-trivial ququint stabilizer code with a transversal non-Clifford gate  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104)).
Analogous qubit and qutrit quantum RM codes require 15 and 8 qudits, respectively  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104)).

A stabilizer tableau for the code is  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104))
\begin{align}
\begin{array}{cccc}
  X & X^{2} & X^{3} & X^{4} \\
  Z & Z^{2} & Z^{3} & Z^{4} \\
  Z & Z^{4} & Z^{4} & Z
\end{array}~.
\end{align}
The $X$-type generator spans the shortened first-order GRM code of length four, and the $Z$-type generators span the dual of the code generated by $(1,2,3,4)$ and the all-ones vector  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104)).

The code admits the codewords
\begin{align}
  |\overline{j}\rangle = \frac{1}{\sqrt{5}} \sum_{a=0}^{4} |a+j,\,2a+j,\,3a+j,\,4a+j\rangle~,
\end{align}
where $j\in\mathbb{Z}_5$ labels the logical ququint and where addition is modulo five.

(source: raw/error-correction-zoo.md)

## Transversal gates

- Logical Pauli operators are $\overline{X} = X^{\otimes 4}$ and $\overline{Z} = (Z^{\dagger})^{\otimes 4}$  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104)).
- Applying the diagonal gate
\begin{align}
  M = \mathrm{diag}\left(\omega^{3},\omega,\omega^{-1},\omega^{-2},\omega^{-1}\right)~,\quad\quad \omega = e^{2\pi i/5}
\end{align}
to every ququint implements the logical $\overline{M}^{\dagger}$  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104)).
This non-Clifford gate lies in the third level of the qudit Clifford hierarchy  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104)).
It is Clifford-equivalent to the modular-qudit $T$ gate  ([arXiv:1206.1598](https://arxiv.org/abs/1206.1598), [arXiv:1406.3055](https://arxiv.org/abs/1406.3055)).

## Magic scaling exponent

Magic-state yield parameter $\gamma = \log_D (n/k) = \log_2 4 = 2$ for distance $D=2$  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104)).

## Threshold

- Magic-state distillation threshold of $\epsilon^{*}_{\mathrm{dep}} \approx 0.363$ against depolarizing noise and $\epsilon^{*} \approx 0.312$ against arbitrary noise, assuming noiseless Clifford operations  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104)). Both thresholds refer to the error probability $\epsilon = 1-\langle M_0|\rho|M_0\rangle$ of the input magic states $|M_0\rangle = M|+\rangle$. The depolarizing-noise threshold corresponds to a depolarizing rate of about $0.45$  ([arXiv:1205.3104](https://arxiv.org/abs/1205.3104)).
