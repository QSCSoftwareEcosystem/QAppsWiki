## Description

Self-dual doubly-even CSS code obtained by binarizing each $\mathbb{F}_4$ qudit of the $⟦5,1,3⟧_4$ Galois-qudit CSS code into two qubits and encoding each pair into a $⟦4,2,2⟧$ block  ([arXiv:2601.20927](https://arxiv.org/abs/2601.20927)).
Since that Galois-qudit code is a symplectic double of the $⟦5,1,3⟧$ five-qubit code  ([arXiv:2601.20927](https://arxiv.org/abs/2601.20927)), the code is also the concatenated symplectic double of the five-qubit code  ([arXiv:1004.3791](https://arxiv.org/abs/1004.3791)) ([arXiv:2605.15344](https://arxiv.org/abs/2605.15344)).

Binarization uses the self-dual normal basis $\{\omega,\omega^2\}$ of $\mathbb{F}_4$ and yields the $⟦10,2,3⟧$ binarized Galois-qudit code  ([arXiv:2601.20927](https://arxiv.org/abs/2601.20927)).
Physical qubits are arranged in five blocks of four, where block $j$ corresponds to the $j$-th $\mathbb{F}_4$ qudit of the $⟦5,1,3⟧_4$ code.
Using the concatenation convention of the Zoo, the $⟦10,2,3⟧$ code is the inner code and the $⟦4,2,2⟧$ code is the outer code.
Stabilizer generators of the $⟦4,2,2⟧$ outer code on each block are $ZZZZ$ and $XXXX$.
The inner stabilizers are the lifted images of the eight stabilizer generators of the $⟦10,2,3⟧$ code.
The lift uses the logical-operator map $X^\omega\mapsto XXII$, $X^{\omega^2}\mapsto XIXI$, $Z^\omega\mapsto IZIZ$, $Z^{\omega^2}\mapsto IIZZ$ within each block  ([arXiv:2601.20927](https://arxiv.org/abs/2601.20927)).

## Protection

Detects errors on up to 5 qubits and corrects errors on up to 2 qubits.

## Encoders

- Non-fault-tolerant encoding circuits  ([arXiv:2605.15344](https://arxiv.org/abs/2605.15344)).

## Transversal gates

- Logical CNOT gates in both directions between the two logical qubits are realized by qubit permutations within a code block  ([arXiv:2601.20927](https://arxiv.org/abs/2601.20927), [arXiv:2605.15344](https://arxiv.org/abs/2605.15344)).
- Fold-diagonal logical $SS$ gates are available from the self-duality of the inner $⟦5,1,3⟧_4$ code and the outer $⟦4,2,2⟧$ layer  ([arXiv:2601.20927](https://arxiv.org/abs/2601.20927)).
- All logical Clifford gates can be realized as two-fold transversal gates, i.e., by depth-one circuits of two-local code-preserving physical gates  ([arXiv:2510.18753](https://arxiv.org/abs/2510.18753), [arXiv:2601.20927](https://arxiv.org/abs/2601.20927), [arXiv:2606.13521](https://arxiv.org/abs/2606.13521), [arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).

## Fault tolerance

- Selective state filtering (post-selection): logical error rates of $\approx 2\times 10^{-6}$ per round of Steane-style error correction at physical error rate $p=10^{-3}$, without being fully fault-tolerant  ([arXiv:2605.15344](https://arxiv.org/abs/2605.15344)).
