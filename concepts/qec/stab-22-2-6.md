## Description

Self-dual doubly even CSS code on 22 physical qubits encoding two logical qubits with distance six.
The code is constructed from the self-orthogonal $[22,10,8]$ code obtained by shortening the $[24,12,8]$ extended Golay code on two bits  ([arXiv:1703.07847](https://arxiv.org/abs/1703.07847)).
Since the automorphism group of the extended Golay code is 5-transitive, the code does not depend on which two bits are chosen  ([arXiv:1703.07847](https://arxiv.org/abs/1703.07847)).
The code is also a symplectic double of a pure $⟦11,1,3⟧$ stabilizer code.

(source: raw/error-correction-zoo.md)

## Protection

Detects errors on up to five qubits and corrects errors on up to two qubits.

## Transversal gates

- Code automorphisms and fold-transversal gates generate the full two-qubit Clifford group  ([arXiv:2606.05044](https://arxiv.org/abs/2606.05044)).
