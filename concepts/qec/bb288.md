## Description

A bivariate bicycle (BB) code with parameters $⟦288,12,18⟧$ and weight-six stabilizer generators  ([arXiv:2308.07915](https://arxiv.org/abs/2308.07915)).

One defining presentation uses $(\ell,m)=(12,12)$ with $x^{\ell}=y^{m}=1$, and
$A=x^3+y^2+y^7$, $B=y^3+x+x^2$ in $\mathbb{F}_2[x,y]/(x^{\ell}-1,y^{m}-1)$  ([arXiv:2308.07915](https://arxiv.org/abs/2308.07915)).

(source: raw/error-correction-zoo.md)

## Rate

Ancilla-added encoding rate is $1/48$, using $n_a=n=288$ ancilla qubits.
