## Description

Triorthogonal and quantum divisible code which is the smallest distance-five stabilizer code to admit a transversal $T$ gate  ([arXiv:1012.4134](https://arxiv.org/abs/1012.4134)) ([arXiv:1209.2426](https://arxiv.org/abs/1209.2426)).
It is one example of a level-three generalized divisible code obtainable from the doubling transformation  ([arXiv:1709.08658](https://arxiv.org/abs/1709.08658)).
Its $X$-type stabilizers form a triply even linear binary code in the symplectic representation.

(source: raw/error-correction-zoo.md)

## Magic scaling exponent

The code yields an exponent $\gamma = \log 49 / \log 5 \approx 2.42$.

## Transversal gates

- The code admits a transversal $T$ gate  ([arXiv:1209.2426](https://arxiv.org/abs/1209.2426)).
