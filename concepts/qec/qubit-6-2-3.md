## Description

Six-qubit code that realizes gates from the group $\mathbb{Z}_{10}$ transversally.
This is the smallest known distance-three code supporting a transversal gate outside of the Clifford group.
See Ref.  ([arXiv:2504.20847](https://arxiv.org/abs/2504.20847)) for the codewords.

(source: raw/error-correction-zoo.md)

## Transversal gates

- The $\mathbb{Z}_{10}$ group can be realized transversally  ([arXiv:2504.20847](https://arxiv.org/abs/2504.20847)). This is the smallest known distance-three code supporting a transversal gate outside of the Clifford group.
