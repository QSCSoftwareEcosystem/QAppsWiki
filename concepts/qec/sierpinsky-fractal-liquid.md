## Description

A fractal type-I fracton CSS code defined on a cubic lattice  ([arXiv:1908.08049](https://arxiv.org/abs/1908.08049)).
The code admits an excitation-moving operator shaped like a Sierpinski triangle  ([arXiv:1908.08049](https://arxiv.org/abs/1908.08049)).
