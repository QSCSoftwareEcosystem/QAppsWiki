## Description

A bivariate bicycle (BB) code with parameters $⟦108,8,10⟧$ and weight-six stabilizer generators  ([arXiv:2308.07915](https://arxiv.org/abs/2308.07915)).

One defining presentation uses $(\ell,m)=(9,6)$ with $x^{\ell}=y^{m}=1$, and
$A=x^3+y+y^2$, $B=y^3+x+x^2$ in $\mathbb{F}_2[x,y]/(x^{\ell}-1,y^{m}-1)$  ([arXiv:2308.07915](https://arxiv.org/abs/2308.07915)).

(source: raw/error-correction-zoo.md)

## Rate

Ancilla-added encoding rate is $1/27$, using $n_a=n=108$ ancilla qubits.
