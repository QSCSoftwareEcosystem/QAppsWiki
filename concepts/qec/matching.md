## Description

Member of a class of qubit stabilizer codes based on the Abelian phase of the Kitaev honeycomb model.

(source: raw/error-correction-zoo.md)

## Realizations

- Braiding of defects has been demonstrated for a five-qubit version of the code  ([arXiv:1609.07774](https://arxiv.org/abs/1609.07774)).
