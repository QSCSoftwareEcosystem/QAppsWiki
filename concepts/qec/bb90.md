## Description

A bivariate bicycle (BB) code with parameters $⟦90,8,10⟧$ and weight-six stabilizer generators  ([arXiv:2308.07915](https://arxiv.org/abs/2308.07915)).

One defining presentation uses $(\ell,m)=(15,3)$ with $x^{\ell}=y^{m}=1$, and
$A=x^9+y+y^2$, $B=1+x^2+x^7$ in $\mathbb{F}_2[x,y]/(x^{\ell}-1,y^{m}-1)$  ([arXiv:2308.07915](https://arxiv.org/abs/2308.07915)).

(source: raw/error-correction-zoo.md)

## Rate

Ancilla-added encoding rate is $2/45\approx 0.044$, using $n_a=n=90$ ancilla qubits.
