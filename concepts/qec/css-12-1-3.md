## Description

Twelve-qubit constant-excitation (CE) CSS code that encodes one logical qubit with distance three.
It is the smallest CE CSS code that corrects a single-qubit error  ([arXiv:2507.10395](https://arxiv.org/abs/2507.10395)).
Codewords lie in a fixed Hamming-weight subspace, making the code immune to coherent noise in the form of transversal $Z$-rotations.

One stabilizer tableau for the code is, up to Pauli frame  ([arXiv:2507.10395](https://arxiv.org/abs/2507.10395)),
\begin{align}
\begin{array}{cccccccccccc}

  I & I & X & X & X & X & I & I & I & I & I & I \\

## Protection

Corrects any single-qubit error (distance $d=3$).
Protects from collective coherent noise in the form of transversal $Z$-rotations, since all codewords lie in the same Hamming-weight subspace  ([doi:10.1109/ISIT45174.2021.9518206](https://doi.org/10.1109/ISIT45174.2021.9518206), [arXiv:2011.00197](https://arxiv.org/abs/2011.00197)).

## Fault tolerance

- Fault-tolerant syndrome extraction using modified Shor and Steane methods adapted for CE codes: weight-$2w$ stabilizers are measured using $w$-CE cat states, and zero-controlled NOT ($\mathrm{C}_0 X$) gates replace standard CNOT gates to preserve the constant-excitation structure  ([arXiv:2507.10395](https://arxiv.org/abs/2507.10395)).

## Threshold

- Pseudo-threshold of $\sim 9.28 \times 10^{-4}$ (circuit-level stochastic noise) and $\sim 5.98 \times 10^{-4}$ (with coherent corrections, $\gamma = 0.01$) under collective coherent noise  ([arXiv:2507.10395](https://arxiv.org/abs/2507.10395)).
