# Bravyi-Bacon-Shor (BBS) code

## Description

A CSS subsystem stabilizer code generalizing Bacon-Shor codes to a larger set of qubit geometries.
Defined through a binary matrix $A$ such that physical qubits live on sites $(i,j)$ whenever $A_{i,j}=1$.
The gauge group is generated by 2-qubit operators, including $XX$ interactions between any two qubits sharing a column in $A$, and $ZZ$ interactions between any two qubits sharing a row.

(source: raw/error-correction-zoo.md)

## Protection

The code parameters are $n=\sum_{i,j}A_{i,j}$, $k=\text{rank}(A)$, and $d$ is the minimum of the distances of the linear binary codes generated by the rows and columns of $A$  ([arXiv:1008.1029](https://arxiv.org/abs/1008.1029)).

## Rate

A class of BBS codes  ([arXiv:1901.06319](https://arxiv.org/abs/1901.06319)) saturate the subsystem bound $kd = O(n)$  ([arXiv:1008.1029](https://arxiv.org/abs/1008.1029)).
