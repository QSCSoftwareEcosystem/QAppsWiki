## Description

Member of one of two families of fracton codes, named HH-I and HH-II, defined on a cubic lattice with two qubits per site.
HH-I (HH-II) is a CSS (non-CSS) stabilizer code family, with the former identified as a foliated type-I fracton code that is decomposable into two separate lattice models  ([arXiv:1908.08049](https://arxiv.org/abs/1908.08049)).
The sorting analysis of Ref.  ([arXiv:1908.08049](https://arxiv.org/abs/1908.08049)) leaves HH-II inconclusive, consistent with either a fractal type-I or a type-II fracton phase.
