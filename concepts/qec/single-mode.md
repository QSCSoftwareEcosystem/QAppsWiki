## Description

Encodes a $K$-dimensional Hilbert space into a single bosonic mode. A trivial single-mode code encoding a qubit into the first two Fock states $\{|0\rangle,|1\rangle\}$ is called the *single-rail* encoding  ([arXiv:quant-ph/0007106](https://arxiv.org/abs/quant-ph/0007106), [arXiv:quant-ph/0205044](https://arxiv.org/abs/quant-ph/0205044)).
