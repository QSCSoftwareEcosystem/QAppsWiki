## Description

A four-qubit CSS stabilizer code that is the only qubit CSS code with such parameters.

A stabilizer tableau for the code is given by 
\begin{align}
\begin{array}{cccc}
  X & X & I & I \\
  I & I & X & X \\
  Z & Z & Z & Z
\end{array}~.
\end{align}
The code is depicted in \ref{figure:css-412-operators}.


The code admits the following basis of codewords,
\begin{align}
  \begin{split}
    |\overline{0}\rangle = (|0000\rangle + |1111\rangle)/\sqrt{2}~{\phantom{.}}\\
    |\overline{1}\rangle = (|0011\rangle + |1100\rangle)/\sqrt{2}~.
  \end{split}
\end{align}
It is realized as the $\{|\overline{00}\rangle,|\overline{01}\rangle\}$ subcode of the $⟦4,2,2⟧$ four-qubit code  ([arXiv:quant-ph/9704002](https://arxiv.org/abs/quant-ph/9704002)), and the subcodes spanned by $|\overline{00}\rangle$ and any other $⟦4,2,2⟧$ codeword are equivalent to it.
Applying the Pauli string $IXIX$ to its codewords yields an equivalent constant-excitation $⟦4,1,2⟧$ code.

The code's $\pm$-basis codewords can be written as
\begin{align}
  |\overline{\pm}\rangle = \frac{1}{2}(|00\rangle \pm |11\rangle)^{\otimes 2}~.
\end{align}
This code can be thought of as a concatenation of a two-qubit bit-flip with a two-qubit phase-flip code.

(source: raw/error-correction-zoo.md)

## Protection

Detects a single-qubit error or single erasure as a distance-two code.
The code also approximately corrects a single AD error, with recovery fidelity $1-5\gamma^2+O(\gamma^3)$  ([arXiv:quant-ph/9704002](https://arxiv.org/abs/quant-ph/9704002)).
A complementary-channel analysis shows that the optimal worst-case entanglement-fidelity distance for this code under AD noise is of order $\gamma$, improving over the uncorrected order $\sqrt{\gamma}$, and that no recovery can improve this asymptotic scaling  ([arXiv:0907.5391](https://arxiv.org/abs/0907.5391)).
The $\{|\overline{01}\rangle,|\overline{11}\rangle\}$ $⟦4,1,2⟧$ subcode  ([arXiv:quant-ph/0103042](https://arxiv.org/abs/quant-ph/0103042)) also approximately corrects a single AD error, and is a constant-excitation code.

## Realizations

- Linear optical networks  ([arXiv:0804.2268](https://arxiv.org/abs/0804.2268), [arXiv:1404.5498](https://arxiv.org/abs/1404.5498)).
- Superconducting-circuit devices  ([arXiv:1912.09410](https://arxiv.org/abs/1912.09410), [arXiv:2102.06132](https://arxiv.org/abs/2102.06132)).
- Logical gates within one block  ([arXiv:2102.13071](https://arxiv.org/abs/2102.13071)) and between two blocks  ([arXiv:2006.03071](https://arxiv.org/abs/2006.03071)), with the latter interpreted as lattice surgery between planar surface codes, were realized in superconducting circuits.
- Neutral atom arrays by Atom Computing ran the Bernstein-Vazirani algorithm on up to 28 logical qubits  ([arXiv:2411.11822](https://arxiv.org/abs/2411.11822)).
- Break-even performance has been demonstrated on a superconducting IBM device using the syndrome-based Petz recovery  ([arXiv:2510.08719](https://arxiv.org/abs/2510.08719)).
- Implementation of a universal logical gate set in superconducting circuits by Origin Quantum Computing  ([arXiv:2405.09035](https://arxiv.org/abs/2405.09035)).
