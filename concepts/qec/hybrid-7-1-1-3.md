## Description

A distance-three seven-qubit hybrid stabilizer code storing one qubit and one classical bit.
Admits a stabilizer generator set with a weight-two generator, which delineates the underlying classical code  ([arXiv:1911.12260](https://arxiv.org/abs/1911.12260)).
