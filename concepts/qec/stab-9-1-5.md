## Description

Nine-qutrit pure Hermitian code that is the smallest qutrit stabilizer code to correct two-qutrit errors.

See  ([arXiv:2108.08088](https://arxiv.org/abs/2108.08088)) for its stabilizer generator matrix.

(source: raw/error-correction-zoo.md)

## Protection

Smallest stabilizer code that protects against errors on any two qutrits. Detects four-qutrit errors.
