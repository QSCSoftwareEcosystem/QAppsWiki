## Description

Bivariate tricycle code that can code switch into a BB code and that admits a depth-two cup-product $CCZ$ gate  ([arXiv:2510.07269](https://arxiv.org/abs/2510.07269)).
It is defined over $\mathbb{F}_2[x,y]/(x^3+1,y^9+1)$ by the binomial elements $a=xy^3+x^2y$, $b=1+xy^8$, and $c=x^2y^4+x^2y^6$  ([arXiv:2510.07269](https://arxiv.org/abs/2510.07269)).

Dropping $c$ yields the 2D component code $LP(a,b)$, the $⟦54,2,6⟧$ BB code  ([arXiv:2510.07269](https://arxiv.org/abs/2510.07269)).
Since $|G|=27$ is odd and $c=(y^3+y^4)a+(xy^6+xy^7)b$ lies in the ideal $(a,b)$, a one-way transversal CNOT couples each BB logical qubit to a distinct tricycle logical qubit  ([arXiv:2510.07269](https://arxiv.org/abs/2510.07269)).

(source: raw/error-correction-zoo.md)

## Protection

$d=d_Z=5$ and $d_X>d_Z$  ([arXiv:2510.07269](https://arxiv.org/abs/2510.07269)).

## General gates

- Depth-two logical $CCZ$ circuit via the cup product  ([arXiv:2510.07269](https://arxiv.org/abs/2510.07269)).
