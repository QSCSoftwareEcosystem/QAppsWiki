## Description

A bivariate bicycle (BB) code with parameters $⟦72,12,6⟧$ and weight-six stabilizer generators  ([arXiv:2308.07915](https://arxiv.org/abs/2308.07915)).

One defining presentation uses $(\ell,m)=(6,6)$ with $x^{\ell}=y^{m}=1$, and
$A=x^3+y+y^2$, $B=y^3+x+x^2$ in $\mathbb{F}_2[x,y]/(x^{\ell}-1,y^{m}-1)$  ([arXiv:2308.07915](https://arxiv.org/abs/2308.07915)).

(source: raw/error-correction-zoo.md)

## Rate

Ancilla-added encoding rate is $1/12$, using $n_a=n=72$ ancilla qubits.

## Decoders

- [Frontier decoder](https://github.com/aleverrier/frontier), a pruned dynamic-programming decoder, under circuit-level noise  ([arXiv:2606.20513](https://arxiv.org/abs/2606.20513)).
