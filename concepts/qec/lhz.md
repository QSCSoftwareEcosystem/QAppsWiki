## Description

A $⟦k(k+1)/2,k⟧$ QLDPC CSS code whose physical qubits store logical bits and their pairwise parities.
It was originally designed to convert the long-range interactions of a quantum annealer into local constraints  ([doi:10.1126/sciadv.1500838](https://doi.org/10.1126/sciadv.1500838), [arXiv:1511.00004](https://arxiv.org/abs/1511.00004)).
Diagonal logical gates become physical single-qubit $Z$-rotations at arbitrary angle  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)).

Its stabilizer group is generated by $Z$-type parity constraints, and each logical $X$ operator is supported on a *logical line*, the set of all physical qubits whose label contains a given logical index.
The code becomes a universal quantum computing architecture once a row of *data qubits*, one per logical qubit, is added  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)).
An extension maps more general models onto the same lattice  ([arXiv:2105.06233](https://arxiv.org/abs/2105.06233)).

For $k$ logical qubits, the layout with data qubits consists of one data qubit per logical qubit and one parity qubit per pair of logical qubits  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505), [arXiv:2609.19250](https://arxiv.org/abs/2609.19250)).
The data qubit $(i)$ satisfies $\overline{Z}_i = Z_i$, while the parity qubit $(ij)$ satisfies $\overline{Z}_i\overline{Z}_j = Z_{ij}$.
The stabilizer group is generated by the $k(k-1)/2$ weight-three checks $Z_i Z_j Z_{ij}$, one per pair of logical qubits.
Physical qubits can be identified with the vertices and edges of the complete graph $K_k$, with one check per edge  ([arXiv:2609.19250](https://arxiv.org/abs/2609.19250)).
The original formulation  ([doi:10.1126/sciadv.1500838](https://doi.org/10.1126/sciadv.1500838)) contains only parity qubits, and is the same code with one fewer logical qubit.
Fixing a reference logical index and identifying each parity qubit whose label contains that index with a data qubit maps the two formulations onto each other.

(source: raw/error-correction-zoo.md)

## Protection

The $X$-distance is the number of physical qubits in the shortest logical line, which is $k$ for the layout with data qubits  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)).
Up to $\lfloor (d_x-1)/2 \rfloor$ simultaneous bit-flip errors can be corrected  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)).
Every logical $Z$ operator has a weight-one representative on a data qubit, so phase errors are not protected.

## Encoders

- Arbitrary quantum states  ([arXiv:2303.08602](https://arxiv.org/abs/2303.08602)).
- Parity qubits are added or removed one at a time by two CNOT gates from the qubits of the corresponding constraint  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)). This allows partial encoding and decoding during a computation, and switching between layouts with different numbers of parity qubits  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)).
- Any $k$-qubit graph state can be prepared in the LHZ encoding in circuit depth at most $k+3$ with $2k(k-1)$ CNOT gates  ([arXiv:2205.09517](https://arxiv.org/abs/2205.09517)).
- Encoding circuit of depth $k+1$, obtained by commuting and cancelling the CNOT gates of the iterative procedure  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)). The reversed sequence decodes.

## Transversal gates

- Logical operators are $\overline{Z}_i = Z_i$ and $\overline{X}_i = \prod_{A \ni i} X_A$, the product running over every physical qubit whose label contains $i$.
- Diagonal logical gates are physical single-qubit $Z$-rotations at arbitrary angle  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)). A rotation on the parity qubit $(ij)$ is a logical two-qubit diagonal rotation on logical qubits $i$ and $j$. The logical controlled-phase gate is the depth-one product $\overline{\mathrm{CP}}^{(i,j)}_{\phi}=R_z^{(i)}(\phi/2)R_z^{(ij)}(-\phi/2)R_z^{(j)}(\phi/2)$  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)).
- One layer of physical $S$ gates and their powers realizes every addressable logical $S$ and CZ gate, with $\overline{S}_i=S_i$ and $\overline{\mathrm{CZ}}_{ij}=S_i S_j S_{ij}^{\dagger}$  ([arXiv:2609.19250](https://arxiv.org/abs/2609.19250)). The code thus realizes the full group $\mathcal{U}(2k,2)=\langle S_k,\mathrm{CZ}_k\rangle$ of addressable diagonal Clifford gates by transversal single-qubit Clifford gates, at the minimum possible block length $n=k(k+1)/2$, of order $\Theta(k^2)$  ([arXiv:2609.19250](https://arxiv.org/abs/2609.19250)).

## General gates

- Logical $X$-rotations use a chain of $2(k-1)$ CNOT gates along a logical line together with one physical $X$-rotation  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505), [arXiv:2205.09517](https://arxiv.org/abs/2205.09517)).
The circuit depth is $2\lceil k/2 \rceil+1$ for $k>4$  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)).
Together with logical $Z$-rotations and controlled-phase gates, they form a universal gate set  ([arXiv:2205.09505](https://arxiv.org/abs/2205.09505)).

## Decoders

- BP decoder  ([arXiv:1511.00004](https://arxiv.org/abs/1511.00004)).
