## Description

Quantum error correcting code associated with the Levin-Wen string-net model with the Fibonacci input category, admitting two types of encodings.

The first type of encoding is into the ground-state subspace of the Levin-Wen model Hamiltonian, defined on a cell decomposition (dual to a triangulation) of a surface with a qubit on each link. The code space is the simultaneous $+1$ eigenspace of a set of vertex operators and plaquette operators, which are defined by the fusion rules and the numerical data of the Fibonacci category, respectively.
In the corresponding doubled Fibonacci theory, the anyon types are $1 \times 1$, $1 \times \tau$, $\tau \times 1$, and $\tau \times \tau$  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816)).

The second type of encoding is into the degenerate fusion space of a number of anyonic quasiparticle excitations of the Levin-Wen model. In the computational scheme of Ref.  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816)), logical information is encoded into pairs of $\tau \times \tau$ anyons that fuse to $1 \times 1$. This can equivalently be constructed by braiding holes in a spherical geometry  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816)).

(source: raw/error-correction-zoo.md)

## Protection

When defined on a $L \times L$ tailed honeycomb tiling on a torus, the code distance for ground-state encoding is $L$.

## Encoders

- Code states may not be preparable with an adaptive constant-depth circuit with geometrically local gates and measurements throughout  ([arXiv:2209.06202](https://arxiv.org/abs/2209.06202)).
- Ground-state initialization on small lattice  ([arXiv:2407.21761](https://arxiv.org/abs/2407.21761)).
- Fusion-space initialization can be reduced to preparing pairs of $\tau \times \tau$ anyons by local cut-and-glue procedures and small projective measurements  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816)).

## Transversal gates

- A universal transversal gate set could be implemented in a folded version of this code using the techniques introduced in Ref  ([arXiv:1711.05752](https://arxiv.org/abs/1711.05752)).

## General gates

- Universal gate set for the ground-state encoding is implemented through topological operations corresponding to elements of the mapping class group, which is generated by Dehn-twists along non-contractible cycles. These Dehn-twists can be implemented using constant-depth circuits when allowing long-range permutations of qubits  ([arXiv:1806.02358](https://arxiv.org/abs/1806.02358), [arXiv:1806.06078](https://arxiv.org/abs/1806.06078)). The mapping class group of a disk with $m$ punctures is the braid group of $m$ objects.
- Universal gate set for the fusion-space encoding is implemented through braiding of the computational anyons  ([arXiv:quant-ph/0001108](https://arxiv.org/abs/quant-ph/0001108), [arXiv:1002.2816](https://arxiv.org/abs/1002.2816)). In the lattice realization of Ref.  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816)), these braids and the associated Dehn twists are enacted by local $F$-moves, and readout reduces to measuring anyon labels on a fixed edge after local retriangulations. Circuit-based gates can be converted into braid patterns via quantum compiling algorithms  ([arXiv:1310.4150](https://arxiv.org/abs/1310.4150), [arXiv:2008.10790](https://arxiv.org/abs/2008.10790)).

## Decoders

- Clustering decoder (provides best known threshold for this code)  ([arXiv:1506.03815](https://arxiv.org/abs/1506.03815), [arXiv:1607.02159](https://arxiv.org/abs/1607.02159), [arXiv:2012.04610](https://arxiv.org/abs/2012.04610)).
- Fusion-aware iterative minimum-weight perfect matching decoder. Note that ordinary MWPM decoders do not produce a threshold with this code  ([arXiv:2012.04610](https://arxiv.org/abs/2012.04610)).
- Cellular automaton decoder  ([arXiv:2301.00054](https://arxiv.org/abs/2301.00054)).

## Code capacity threshold

- $4.7\%$ for depolarizing noise, $7.3\%$ for dephasing noise, and $3.8\%$ for bit-flip noise with clustering decoder, assuming perfect measurements and gates  ([arXiv:2012.04610](https://arxiv.org/abs/2012.04610)). See also Ref.  ([arXiv:1506.03815](https://arxiv.org/abs/1506.03815)).
- $3.0\%$ for depolarizing noise, $6.0\%$ for dephasing noise, and $2.5\%$ for bit-flip noise with fusion-aware iterative MWPM decoder, assuming perfect measurements and gates  ([arXiv:2012.04610](https://arxiv.org/abs/2012.04610)).

## Threshold

- Between $10^{-2}\%$ and $5\cdot 10^{-2}\%$ for pair-creation and measurement noise  ([arXiv:2301.00054](https://arxiv.org/abs/2301.00054)).

## Realizations

- NMR: Implementation of braiding-based Hadamard gate on two qubits  ([arXiv:2210.12145](https://arxiv.org/abs/2210.12145)).
- Superconducting qubits: state preparation, fusion, and braiding  ([arXiv:2404.00091](https://arxiv.org/abs/2404.00091), [arXiv:2406.12820](https://arxiv.org/abs/2406.12820)). The latter work utilized DSNP and sampled the string-net wavefunction to estimate the underlying chromatic polynomial.
