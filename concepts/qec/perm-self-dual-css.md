## Description

A qubit CSS code whose $X$- and $Z$-type stabilizer groups are exchanged by a permutation of the physical qubits.
Equivalently, a qubit CSS code for which transversal Hadamard followed by a qubit permutation is a logical operation.

More technically, let $C_X$ and $C_Z$ be the $X$- and $Z$-type stabilizer spaces of an $⟦n,k⟧$ CSS code.
A code is permutationally self-dual (PSD) if there is a permutation $\pi \in S_n$ with $\pi(C_X)=C_Z$ and $\pi(C_Z)=C_X$  ([arXiv:2609.19250](https://arxiv.org/abs/2609.19250)).
Equivalently, the physical operator $U_\pi H^{\otimes n}$ preserves the stabilizer group  ([arXiv:2609.19250](https://arxiv.org/abs/2609.19250)).
Such a $\pi$ is called an $XZ$-duality, $ZX$-duality  ([arXiv:2202.06647](https://arxiv.org/abs/2202.06647)), or em symmetry  ([arXiv:2401.17359](https://arxiv.org/abs/2401.17359)).

A CSS code on $2n$ qubits is the symplectic double of an $n$-qubit stabilizer code iff it admits a fixed-point-free involutory $XZ$-duality  ([arXiv:2406.09951](https://arxiv.org/abs/2406.09951)).
The halved code is read off along the orbits of the duality, with the two qubits of each orbit supplying the $X$ and $Z$ coordinates of one qubit.
Inequivalent stabilizer codes can have equivalent symplectic doubles  ([arXiv:2406.09951](https://arxiv.org/abs/2406.09951)).

Ref.  ([arXiv:2607.21160](https://arxiv.org/abs/2607.21160)) instead defines em symmetry by the weaker condition $H_X = P_1 H_Z P_2$ for some permutation matrices $P_1$ and $P_2$.
Ref.  ([arXiv:1804.01950](https://arxiv.org/abs/1804.01950)) calls this condition weak self-duality.
Every PSD code satisfies this condition for a suitable choice of parity-check matrices.
The condition only requires some qubit permutation to carry $C_Z$ onto $C_X$.
Such a permutation need not also carry $C_X$ onto $C_Z$.

(source: raw/error-correction-zoo.md)

## Protection

A qubit permutation exchanging the $X$- and $Z$-type stabilizer spaces maps the supports of $X$-type logical operators onto the supports of $Z$-type ones.
The $X$- and $Z$-type distances of a PSD code are therefore equal.
The same permutation maps the bit-flip decoding problem onto the phase-flip decoding problem.
Maximum-likelihood decoding thus succeeds with equal probability in both sectors when bit and phase flips occur independently with equal probability  ([arXiv:1804.01950](https://arxiv.org/abs/1804.01950)).

## Transversal gates

- An $XZ$-duality yields Hadamard-type and phase-type fold-transversal Clifford gates, each realized by one layer of physical Clifford gates together with one qubit permutation  ([arXiv:2202.06647](https://arxiv.org/abs/2202.06647)).
- A qubit permutation composed with transversal Hadamard is a logical Clifford gate. In any CSS logical basis, every such self-duality automorphism induces a pure exchange-type logical Clifford, i.e., one whose symplectic representation has vanishing diagonal blocks  ([arXiv:2609.19250](https://arxiv.org/abs/2609.19250)).
- Permutational self-duality is necessary for exchange-type logical actions. An indecomposable CSS code can host logical $H^{\otimes k}$, $(SH)^{\otimes k}$, $(HS)^{\otimes k}$, or any mixture of these up to composition with logical $S$, CX and CZ circuits, implemented by single-qubit Cliffords and qubit permutations in a CSS logical basis, only if the code is PSD  ([arXiv:2609.19250](https://arxiv.org/abs/2609.19250)).
- For an indecomposable PSD-but-not-self-dual code, the logical group generated by single-qubit Cliffords and qubit permutations is $\mathrm{Trans} \rtimes \mathrm{Perm}.2$  ([arXiv:2609.19250](https://arxiv.org/abs/2609.19250)). Transversal single-qubit Cliffords realize at most $\mathcal{U}(2\lfloor k/2 \rfloor,2)^2$, acting on two disjoint halves of the logical qubits, so their number is at most $2^{\lfloor k/2 \rfloor(\lfloor k/2 \rfloor+1)}$  ([arXiv:2609.19250](https://arxiv.org/abs/2609.19250)).

## Code capacity threshold

- The clean statistical mechanical model of a PSD code under bit-flip noise is finite-size Kramers-Wannier self-dual up to a Hadamard mixing of logical sectors  ([arXiv:2607.21160](https://arxiv.org/abs/2607.21160)). For a PSD code family with a unique threshold, this model is self-dual in the thermodynamic limit iff the asymptotic rate vanishes  ([arXiv:2607.21160](https://arxiv.org/abs/2607.21160)). For such zero-rate families, the fully postselected critical point is pinned to the self-dual value $p = 1/(2+\sqrt{2}) \approx 0.2929$  ([arXiv:2607.21160](https://arxiv.org/abs/2607.21160)).
- For zero-rate PSD families with a unique threshold, the principal Boltzmann factor construction in the replica limit gives an approximate phase boundary above the Nishimori line under bit-flip noise  ([arXiv:2607.21160](https://arxiv.org/abs/2607.21160)). Treating erasures as bond dilution extends the same approximation to mixed bit-flip and erasure noise  ([arXiv:2607.21160](https://arxiv.org/abs/2607.21160)).
