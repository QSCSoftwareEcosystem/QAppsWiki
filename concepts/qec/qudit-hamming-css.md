## Description

A family of CSS codes extending quantum Hamming codes to prime qudits of dimension $p$ by expressing the qubit code stabilizers in local-dimension-invariant (LDI) form  ([arXiv:2110.11510](https://arxiv.org/abs/2110.11510)).
