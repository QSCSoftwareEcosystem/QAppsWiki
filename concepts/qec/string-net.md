## Description

A non-stabilizer commuting-projector code whose codewords realize a 2D topological order rendered by a Turaev-Viro topological field theory.
The corresponding anyon theory is defined by a (multiplicity-free) unitary fusion category $ \mathcal{C} $.
The code is defined on a cell decomposition dual to a triangulation of a two-dimensional surface, with a qudit of dimension $ |\mathcal{C}| $ located at each edge of the decomposition.
For modular input categories, the emergent anyon theory is the doubled category $ \mathcal{C}\otimes\mathcal{C}^{*} $  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816)).
These models realize local topological order (LTO)  ([arXiv:2307.12552](https://arxiv.org/abs/2307.12552)).

The codespace is the ground-state subspace of the Levin-Wen model commuting-projector Hamiltonian  ([arXiv:cond-mat/0404617](https://arxiv.org/abs/cond-mat/0404617)), a many-body Hamiltonian realizing the 3-manifold Turaev-Viro invariant  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816), [arXiv:1106.6033](https://arxiv.org/abs/1106.6033)).
For the $\mathbb{Z}_2$ input category on a genus-one handlebody, this construction yields the toric code  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816)).
This Hamiltonian is defined to act on a constrained Hilbert space defined by vertex constraints.
Alternative constructions are possible, encoding information in the fusion space of the low-energy anyonic quasiparticle excitations of the model  ([arXiv:quant-ph/0001108](https://arxiv.org/abs/quant-ph/0001108), [arXiv:1002.2816](https://arxiv.org/abs/1002.2816)).
The fusion space can have dimension greater than one, allowing for topological quantum computation of logical information stored in the fusion outcomes.
Domain walls of string nets can be formulated using bimodule categories  ([arXiv:2008.11187](https://arxiv.org/abs/2008.11187)).
Morita-equivalent string-net models are connected by constant-depth local unitary circuits built from invertible bimodule categories; on a hexagonal lattice, the circuit has depth three and also induces a map between tube-algebra excitations upon adding ancillas  ([arXiv:2112.12757](https://arxiv.org/abs/2112.12757)).
Anyon condensation of general string net models is studied in Ref.  ([arXiv:2303.04711](https://arxiv.org/abs/2303.04711)).

The initial formulation of string-net models  ([arXiv:cond-mat/0404617](https://arxiv.org/abs/cond-mat/0404617)) considered unitary fusion categories with an extra tetrahedral symmetry, but this was realized not to be necessary  ([arXiv:0907.2204](https://arxiv.org/abs/0907.2204), [arXiv:1002.2816](https://arxiv.org/abs/1002.2816)).
Explicit Hamiltonians for the more general categories have been studied  ([arXiv:2004.07045](https://arxiv.org/abs/2004.07045)).

## Encoders

- For an $L\times L$ lattice, deterministic state preparation can be done with a geometrically local unitary $O(L)$-depth circuit  ([arXiv:2110.02020](https://arxiv.org/abs/2110.02020)) or an $O(\log{L})$-depth unitary circuit with non-local two-qubit gates  ([arXiv:0712.0348](https://arxiv.org/abs/0712.0348), [arXiv:0806.4583](https://arxiv.org/abs/0806.4583)).
- Scalable dynamic string-net preparation (DSNP)  ([arXiv:2406.12820](https://arxiv.org/abs/2406.12820)).
- String nets with solvable anyons and gappable boundaries  ([arXiv:0809.3031](https://arxiv.org/abs/0809.3031)) can be prepared via an adaptive finite-depth local unitary circuit  ([arXiv:2411.04985](https://arxiv.org/abs/2411.04985)).
- Suitable initial states can be prepared by locally cutting and gluing regions of the triangulation, reducing the task to preparing small fusion-space states  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816)).

## General gates

- Gates can be implemented through topological operations corresponding to elements of the mapping class group, which is generated by Dehn-twists along non-contractible cycles for triangulations of toroidal  ([arXiv:1806.02358](https://arxiv.org/abs/1806.02358), [arXiv:1806.06078](https://arxiv.org/abs/1806.06078)) and hyperbolic  ([arXiv:1901.11029](https://arxiv.org/abs/1901.11029)) manifolds. Whether or not a gate set is universal depends on the choice of input category; in some cases such as the Ising category, gates can be complemented by topological charge measurements to obtain a universal gate set.
- Alternatively, one could encode the logical quantum information into the degenerate fusion space of a number of computational anyons. In this case, a universal logical gate set can be implemented through the braiding of the computational anyons  ([arXiv:quant-ph/0001108](https://arxiv.org/abs/quant-ph/0001108), [arXiv:math/0103200](https://arxiv.org/abs/math/0103200), [arXiv:1002.2816](https://arxiv.org/abs/1002.2816)), e.g., for the case of the Fibonacci input category.
- In the Levin-Wen realization, braid moves and Dehn twists can be implemented by sequences of local $F$-moves; for general multiplicity-free modular categories these are fixed five-qudit gates, and the same local moves reduce topological-charge measurements to measurements of anyon labels on a fixed edge  ([arXiv:1002.2816](https://arxiv.org/abs/1002.2816)).
