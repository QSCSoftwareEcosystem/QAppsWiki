## Description

Ten-qubit nonadditive CWS code saturating the linear-programming bound for one-error-correcting codes on ten qubits  ([arXiv:0709.1780](https://arxiv.org/abs/0709.1780)).
It was constructed using the coding-clique graph-theoretic framework introduced in  ([arXiv:0709.1780](https://arxiv.org/abs/0709.1780)), which unifies additive and nonadditive code constructions.

The $((10,24,3))$ qubit code can be combined to form an infinite family of distance-three qubit codes whose logical dimension is $50\%$ larger than that of the optimal stabilizer code  ([arXiv:0901.1935](https://arxiv.org/abs/0901.1935)).
