## Description

CSS code that admits a logical $CS$ gate via application of physical $T$ and $T^{\dagger}$ gates.

A stabilizer tableau for the code is given by  ([arXiv:2303.15615](https://arxiv.org/abs/2303.15615))

## Transversal gates

- Logical $CS_{01}$ gate via transversal application of $T$ on qubits $0,3,4,7,8,11$, $T^3$ on qubits $1,2,5,6$, and $T^7 = T^{\dagger}$ on qubits $9,10$  ([arXiv:2303.15615](https://arxiv.org/abs/2303.15615)).
