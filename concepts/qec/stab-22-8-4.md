## Description

Self-dual pure CSS code constructed from a self-orthogonal $[22,7,8]$ classical binary code  ([arXiv:1302.1035](https://arxiv.org/abs/1302.1035)).
All of its logical Clifford gates can be realized by depth-one circuits of two-local code-preserving physical gates  ([arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).

The underlying classical code has weight enumerator $1 + 21y^{8} + 42y^{10} + 42y^{12} + 21y^{14} + y^{22}$; it is even but not doubly even, and it contains the all-ones vector.
Its permutation automorphism group is isomorphic to $PGL(2,7)$, of order 336  ([arXiv:1302.1035](https://arxiv.org/abs/1302.1035)), fixing one distinguished qubit and acting transitively on the remaining 21.

Both an $X$-type and a $Z$-type stabilizer generator are supported on each row of the following stabilizer tableau  ([arXiv:2608.05688](https://arxiv.org/abs/2608.05688))

## Transversal gates

- Qubit permutations combined with transversal CNOT gates between two code blocks realize the full logical linear group $GL(16,2)$ on the 16 logical qubits of the two blocks  ([arXiv:1302.1035](https://arxiv.org/abs/1302.1035)).
- All logical Clifford gates can be realized as two-fold transversal gates, i.e., by depth-one circuits of two-local code-preserving physical gates  ([arXiv:2608.05688](https://arxiv.org/abs/2608.05688)).
