## Description

A 3D topological code defined by a unitary $G$-crossed braided fusion category $ \mathcal{C} $  ([arXiv:1410.4540](https://arxiv.org/abs/1410.4540), [arXiv:1610.07628](https://arxiv.org/abs/1610.07628)), where $G$ is a finite group.
The model realizes TQFTs that include two-gauge theories, those behind Walker-Wang models, as well as the Kashaev TQFT  ([arXiv:1405.5763](https://arxiv.org/abs/1405.5763), [arXiv:1504.01979](https://arxiv.org/abs/1504.01979)).
It has been generalized to include domain walls  ([arXiv:2003.11553](https://arxiv.org/abs/2003.11553)).
