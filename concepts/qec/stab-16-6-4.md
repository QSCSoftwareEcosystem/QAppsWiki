## Description

A (hyperbolic self-dual CSS) 4D color code defined on a tesseract, with stabilizer generators of both types supported on each cube. 
A $⟦16,4,2,4⟧$ tesseract subsystem code can be obtained from this code by using two logical qubits as gauge qubits  ([arXiv:2409.04628](https://arxiv.org/abs/2409.04628)).

## Transversal gates

- Global transversal $S$ implements a logical circuit composed of $CZ$ and $Z$ gates  ([arXiv:2410.07595](https://arxiv.org/abs/2410.07595), [arXiv:1910.09333](https://arxiv.org/abs/1910.09333))
- Transversal Hadamard can be chosen to swap three pairs of logical qubits, allowing even-weight Hadamard-product measurements in magic-state distillation protocols  ([arXiv:1703.07847](https://arxiv.org/abs/1703.07847)).

## General gates

- Using this code as a hyperbolic inner code yields quartic magic-state distillation on six outputs; pipelining it with $⟦4,2,2⟧$ inner-code checks lowers the non-Clifford cost from 390 to 246 noisy $T$ gates  ([arXiv:1703.07847](https://arxiv.org/abs/1703.07847)).

## Decoders

- Post-selected fault-tolerant syndrome extraction  ([arXiv:2008.05051](https://arxiv.org/abs/2008.05051), [arXiv:2112.03785](https://arxiv.org/abs/2112.03785)).

## Fault tolerance

- Post-selected fault-tolerant syndrome extraction  ([arXiv:2008.05051](https://arxiv.org/abs/2008.05051), [arXiv:2112.03785](https://arxiv.org/abs/2112.03785)).

## Realizations

- Trapped-ion devices: logical graph and GHZ states of up to 12 logical qubits constructed using three copies of the $⟦16,4,2,4⟧$ tesseract subsystem code, along with five rounds of post-selected fault-tolerant error correction in a device by Quantinuum  ([arXiv:2409.04628](https://arxiv.org/abs/2409.04628)).
- Neutral atom arrays: deep circuits and 1D-cluster-state creation using 96 logical qubits and hundreds of logical teleportations by the Lukin group  ([arXiv:2506.20661](https://arxiv.org/abs/2506.20661)).
