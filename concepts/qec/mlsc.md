# Majorana loop stabilizer code (MLSC)

## Description

A single-error-correcting fermion-into-qubit encoding defined on a 2D qubit lattice whose stabilizers are associated with loops in the lattice.

(source: raw/error-correction-zoo.md)

## Protection

The code can correct single-qubit errors  ([arXiv:1812.08190](https://arxiv.org/abs/1812.08190)).
