## Description

Seventeen-qubit doubly even 2D color code that admits a transversal implementation of the logical Clifford group.
The smallest distance-five CSS code has $n=17$  ([arXiv:1207.6512](https://arxiv.org/abs/1207.6512)).
It is also a normal self-dual CSS code whose transversal Hadamard acts logically, making it suitable as an inner code for fifth-order magic-state distillation  ([arXiv:1703.07847](https://arxiv.org/abs/1703.07847)).

## Encoders

- Logical zero state preparation using reinforcement learning  ([arXiv:2402.17761](https://arxiv.org/abs/2402.17761)).

## General gates

- As an inner code for magic-state distillation, it yields a 69-to-1 fifth-order routine, or a 49-to-1 pipelined routine when preceded by the Steane code  ([arXiv:1703.07847](https://arxiv.org/abs/1703.07847)).

## Transversal gates

- Transversal implementation of the logical Clifford group.
