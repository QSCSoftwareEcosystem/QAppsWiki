## Description

An $((n,2^k,d))$ qubit stabilizer code is denoted as $⟦n,k⟧$ or $⟦n,k,d⟧$, where $k$ is the number of logical qubits (code dimension), and where $d$ is the code's distance.
The logical subspace is the joint eigenspace of commuting Pauli operators forming the code's stabilizer group $\mathsf{S}$.
Traditionally, the logical subspace is the joint $+1$ eigenspace of a set of $2^{n-k}$ commuting Pauli operators which do not contain $-I$.
The distance is the minimum weight of a Pauli string that implements a nontrivial logical operation in the code.

Qubit stabilizer codes form the joint $+1$-eigenspace of a stabilizer group $\mathsf{S}$, i.e., a group of commuting Paulis that does not contain $-I$ and is generated by $r=n-k$ generators.
The table below summarizes the relevant groups and their sizes for a qubit stabilizer code.

Two qubit stabilizer codes are *equivalent* if the codespace of one code can be mapped into that of the other under a tensor product of elements of the single-qubit Clifford group and a qubit permutation (see Refs.  ([arXiv:quant-ph/9608006](https://arxiv.org/abs/quant-ph/9608006), [arXiv:2501.17447](https://arxiv.org/abs/2501.17447))).
Equivalence under single-qubit Clifford operations is not the same as equivalence under a tensor product of arbitrary single-qubit unitary operations  ([arXiv:0709.1266](https://arxiv.org/abs/0709.1266)) (see also Ref.  ([arXiv:0707.4000](https://arxiv.org/abs/0707.4000)) about this false LC-LU conjecture).
Any qubit stabilizer code is equivalent to a graph quantum code via a single-qubit Clifford circuit  ([arXiv:quant-ph/0111080](https://arxiv.org/abs/quant-ph/0111080)) (see also  ([arXiv:quant-ph/0703112](https://arxiv.org/abs/quant-ph/0703112))).
At the state level, every qubit stabilizer state is equivalent to a graph state under a single-qubit Clifford circuit, and local-Clifford equivalence between graph states is generated by local complementations of the underlying graph  ([arXiv:quant-ph/0308151](https://arxiv.org/abs/quant-ph/0308151)).
In the binary symplectic representation, local-Clifford equivalence of stabilizer states can be tested by solving a system of $n^2$ linear equations in the $4n$ entries of the local Clifford operator  ([arXiv:quant-ph/0308151](https://arxiv.org/abs/quant-ph/0308151)) (see also  ([arXiv:1805.05305](https://arxiv.org/abs/1805.05305), [arXiv:1805.05306](https://arxiv.org/abs/1805.05306), [arXiv:1805.04559](https://arxiv.org/abs/1805.04559))).

A qubit stabilizer code is *decomposable* if there exists a permutation that maps the stabilizer group into a tensor product of two stabilizer groups acting on disjoint sets of qubits.
Otherwise, the code is indecomposable.
For example, a $2n$-qubit code consisting of two copies of an $n$-qubit indecomposable code is decomposable. 

\subsection{Code representations}

Qubit stabilizer states are quadratic-phase states on affine subspaces of $\mathbb{Z}_2^n$: every stabilizer state can be written, up to global phase, as
\begin{align}
|\psi\rangle = 2^{-k/2}\sum_{x\in A} i^{q(x)}(-1)^{\ell(x)} |x\rangle
\end{align}
for some affine subspace $A\subseteq \mathbb{Z}_2^n$, linear function $\ell$, and $\mathbb{Z}_4$-valued quadratic function $q$  ([arXiv:quant-ph/0304125](https://arxiv.org/abs/quant-ph/0304125), [arXiv:quant-ph/0408190](https://arxiv.org/abs/quant-ph/0408190), [arXiv:0811.0898](https://arxiv.org/abs/0811.0898)).
There are efficient ways to compute stabilizer inner products and other functions  ([arXiv:1711.07848](https://arxiv.org/abs/1711.07848)).
For any logical state of a distance-$d$ stabilizer code, the squared overlap with any $n$-qubit product state is at most $2^{1-d}$  ([arXiv:2405.01332](https://arxiv.org/abs/2405.01332)).

Instead of being represented by a basis of codewords, stabilizer codes can be concisely defined and represented by a presentation of the generators of the stabilizer group.  
A set of generators is not unique, and various stabilizer codes admit generators with certain locality properties.

Stabilizer generators can be arranged as rows of a matrix, forming a *stabilizer tableau*. 
For example, a stabilizer tableau of the two-qubit Bell state $|00\rangle + |11\rangle$ is
\begin{align}
\begin{array}{cc}
Z & Z\\
X & X
\end{array}~.
\end{align}
Another stabilizer tableau can be defined by letting $X \to Y$. 

Pauli strings, and the corresponding stabilizer tableaus, can be represented in other ways.

\begin{defterm}{Symplectic representation}
\label{topic:binary-symplectic-representation}
In the symplectic representation, the single-qubit identity, $X$, $Y$, and $Z$ Pauli matrices are represented using two bits as $(0|0)$, $(1|0)$, $(1|1)$, and $(0|1)$, respectively.
In other words, the single-qubit Pauli string $X^a Z^b$ is converted to the vector $a|b$.
The multi-qubit version follows naturally.
\end{defterm}

Each stabilizer code can be represented by a $(n-k) \times 2n$ *check matrix* (a.k.a. *stabilizer generator matrix*) $H=(A|B)$, where each row $(a|b)$ is the symplectic representation of an element from a set of generating elements of the stabilizer group.
The check matrix can be brought into standard form (a.k.a. canonical form) via Gaussian elimination  ([doi:10.1017/CBO9780511976667](https://doi.org/10.1017/CBO9780511976667), [arXiv:2408.15202](https://arxiv.org/abs/2408.15202)).

A pair of $n$-qubit stabilizers with symplectic representation $(a|b)$ and $(a^{\prime}|b^{\prime})$ commute iff their symplectic inner product is zero,
\begin{align}
  a \cdot b^{\prime} + a^{\prime}\cdot b = \sum_{j=1}^{n} a_j b^{\prime}_j + a^{\prime}_j b_j = 0~.
\end{align}
The row space of the check matrix forms a symplectic self-orthogonal binary linear code of length $2n$.

Another correspondence between qubit Pauli matrices and elements of the quaternary Galois field $\mathbb{F}_4$ yields the one-to-one correspondence between qubit stabilizer codes and trace-Hermitian self-orthogonal additive quaternary codes.

\begin{defterm}{$\mathbb{F}_4$ representation}
\label{topic:gf4-representation}
An $n$-qubit Pauli stabilizer can be represented as a length-$n$ quaternary vector using the one-to-one correspondence between the four Pauli matrices $\{I,X,Y,Z\}$ and the four elements $\{0,1,\omega^2,\omega\}$ of the quaternary Galois field $\mathbb{F}_4$.
\end{defterm}

The sets of $\mathbb{F}_4$-represented vectors for all generators yield a trace-Hermitian self-orthogonal additive quaternary code.
In other words, an additive self-orthogonal code $C \subseteq \mathbb{F}_4^n$ of size $2^r$ yields an $⟦n,n-r⟧$ qubit stabilizer code  ([arXiv:quant-ph/9608006](https://arxiv.org/abs/quant-ph/9608006)) ([arXiv:quant-ph/0005008](https://arxiv.org/abs/quant-ph/0005008)).
This classical code corresponds to the stabilizer group $\mathsf{S}$ while its trace-Hermitian dual corresponds to the normalizer $\mathsf{N(S)}$.
In the case of stabilizer states, the correspondence is between such states and trace-Hermitian self-dual quaternary codes; such codes, and therefore such states, have been classified up to equivalence for $n \leq 12$  ([arXiv:quant-ph/0503236](https://arxiv.org/abs/quant-ph/0503236), [arXiv:math/0504522](https://arxiv.org/abs/math/0504522)).
There is a complete set of invariants characterizing stabilizer states up to equivalence  ([arXiv:quant-ph/0410165](https://arxiv.org/abs/quant-ph/0410165), [arXiv:quant-ph/0404106](https://arxiv.org/abs/quant-ph/0404106)).

ZX calculus is complete, sound, and universal for qubit stabilizer codes  ([arXiv:1307.7025](https://arxiv.org/abs/1307.7025)).
Any stabilizer code can be represented by a *ZX canonical form* (ZXCF)  ([arXiv:2411.14448](https://arxiv.org/abs/2411.14448)), and there exist two other representations  ([arXiv:2205.02009](https://arxiv.org/abs/2205.02009), [arXiv:2411.14448](https://arxiv.org/abs/2411.14448)) that utilize ZX calculus.
\begin{defterm}{Encoder-respecting form}
\label{topic:encoder-respecting}
In an *encoder-respecting form*, each qubit stabilizer code  ([arXiv:2411.14448](https://arxiv.org/abs/2411.14448)) (see also Ref.  ([arXiv:2109.10210](https://arxiv.org/abs/2109.10210))) is represented by a semi-bipartite graph with $k$ input and $n$ output nodes in which the $k$ input nodes are not connected to each other.
Conversion from stabilizer tableaus to graphs can be done in time of order $O(n^3)$, while the inverse map from graphs to stabilizer codes can be computed in $O(n^2)$, both using ZX calculus  ([arXiv:2411.14448](https://arxiv.org/abs/2411.14448)).
Properties of the underlying graph are related to properties of the code; for example, bipartite encoder-respecting graphs yield CSS codes, and graph degree controls bounds on code distance, stabilizer weight, and encoding-circuit depth  ([arXiv:2411.14448](https://arxiv.org/abs/2411.14448)).
\end{defterm}

Alternative representations include the *decoupling representation*, in which Pauli strings are represented as vectors over $\mathbb{F}_2$ using three bits  ([arXiv:2305.17505](https://arxiv.org/abs/2305.17505)).

## Protection

Detects errors on up to $d-1$ qubits, and corrects erasure errors on up to $d-1$ qubits.
There are algorithms to calculate the minimum distance  ([arXiv:2109.11996](https://arxiv.org/abs/2109.11996), [arXiv:2308.15140](https://arxiv.org/abs/2308.15140), [arXiv:2408.10743](https://arxiv.org/abs/2408.10743), [arXiv:2409.13017](https://arxiv.org/abs/2409.13017)).
Computing the distance exactly or approximately is generally $NP$-complete, and is $NP$-hard for non-degenerate codes  ([arXiv:2203.04262](https://arxiv.org/abs/2203.04262)).
Distance approximation, minimum-weight stabilizer-generator selection, and decoding are approximately optimal strategies for various quantum lights-out (QLO) games that can be played on the codes' encoder-respecting form  ([arXiv:2411.14448](https://arxiv.org/abs/2411.14448)).

There is the following analogue of the \term{Knill-Laflamme conditions} for qubit stabilizer codes.
Define the normalizer $\mathsf{N(S)}$ of $\mathsf{S}$ to be the set of all Pauli operators that commute with all $S\in\mathsf{S}$.
A stabilizer code can correct a Pauli error set ${\mathcal{E}}$ if and only if $E^\dagger F \notin \mathsf{N(S)}\setminus \mathsf{S}$ for all $E,F \in {\mathcal{E}}$.

There are subtleties with defining degeneracy for non-stabilizer qubit codes with even distance , but they are resolved for stabilizer codes.
A stabilizer code is degenerate with respect to $\mathcal{E}$ if and only if $E^\dagger F \in \mathsf{S}$ for some Pauli strings $E,F \in \mathcal{E}$.
As a distance-$d$ code, a stabilizer code is degenerate if it admits a non-identity stabilizer whose weight is lower than the distance .
Since that stabilizer is in the normalizer, a stabilizer code is degenerate if and only if it is impure.
The pure distance of a qubit stabilizer code is the minimum weight of a non-identity stabilizer, and a qubit stabilizer code is pure if the weight of the lowest-weight stabilizer is the code distance. 
There is a toolkit for studying degenerate codes for Pauli channels  ([arXiv:quant-ph/0604107](https://arxiv.org/abs/quant-ph/0604107)).
The quantum GV bound can be extended into a three-way tradeoff between distance, rate, and stabilizer weight of a qubit stabilizer code  ([arXiv:2411.14448](https://arxiv.org/abs/2411.14448)).  

\begin{defterm}{Cleaning lemma}
\label{topic:cleaning-lemma}
If all logical operators act trivially on some subset of qubits in a stabilizer code, then any logical Pauli operator can be represented on the complementary qubit subset via a stabilizer.
More technically, given any subset $M$ of qubits that is correctable (under erasure), any logical Pauli operator $P$ can be *cleaned off* of $M$ using a stabilizer $S$ such that $PS$ is supported on $M^{\perp}$.
More generally, for any $M$, we have $g(M)+g(M^{\perp}) = 2k$, where $g(M)$ is the number of logical-$X$ and logical-$Z$ Pauli operators supported fully on $M$ (up to stabilizers).
The Cleaning Lemma was originally proven  ([arXiv:0810.1983](https://arxiv.org/abs/0810.1983)), where an analogous result is stated for subsystem codes; see also Ref.  ([arXiv:2204.04699](https://arxiv.org/abs/2204.04699)).
\end{defterm}

Qubit stabilizer codes can be interleaved to protect against burst errors  ([arXiv:quant-ph/0002020](https://arxiv.org/abs/quant-ph/0002020)).
Entropic conditions have been formulated for random projective measurement noise  ([arXiv:2402.00145](https://arxiv.org/abs/2402.00145)).
An effective logical channel can be derived for qubit stabilizer codes under Pauli noise  ([arXiv:2509.16887](https://arxiv.org/abs/2509.16887), [arXiv:2601.15505](https://arxiv.org/abs/2601.15505)).

## Rate

The *ancilla-added rate* is defined as the ratio of logical qubits to the total number of physical qubits including ancillas, $k/(n+c)$, where $c$ is the number of ancilla qubits. The *hashing bound* states that there is a qubit stabilizer code achieving a rate $R = 1 - H(\mathbf{p})$ for a Pauli noise channel with Pauli error probabilities $\mathbf{p}=(p_I,p_X,p_Y,p_Z)$, where $H(\mathbf{p})$ is the entropy of the argument  ([doi:10.1017/CBO9781139525343](https://doi.org/10.1017/CBO9781139525343)). Finite block length bounds and a refinement of the hashing bound have been developed  ([arXiv:2408.15202](https://arxiv.org/abs/2408.15202)).

## Encoders

- Clifford circuits, i.e., those consisting of CNOT, Hadamard, and certain phase gates  ([arXiv:quant-ph/9607030](https://arxiv.org/abs/quant-ph/9607030)), using an algorithm  ([arXiv:2301.02356](https://arxiv.org/abs/2301.02356)) based on the Gottesman-Knill theorem  ([arXiv:quant-ph/0406196](https://arxiv.org/abs/quant-ph/0406196)) or using ZX calculus  ([doi:10.1007/978-3-540-70583-3_25](https://doi.org/10.1007/978-3-540-70583-3_25), [arXiv:0906.4725](https://arxiv.org/abs/0906.4725)). 
Generic constructions use $O(n^2)$ Clifford gates and can be adjusted to realize a chosen set of logical Pauli operators .
Encoding circuits can be done in linear depth, up to logarithmic corrections, for most practical use cases  ([arXiv:2201.05215](https://arxiv.org/abs/2201.05215)). 
\begin{defterm}{Destabilizers}
\label{topic:destabilizers}
A Clifford encoding circuit maps the first $k$ qubits to the logical qubits of the code, and the Pauli $Z$ operators of the last $r = n-k$ qubits are mapped into a set of stabilizer generators.
The set of Pauli $X$ operators of the first $r$ qubits that are mapped into a set of generators for the destabilizer group  ([arXiv:quant-ph/0406196](https://arxiv.org/abs/quant-ph/0406196))}.
Each such generator anticommutes with only one stabilizer generator while commuting with the rest of the stabilizer generators.
\end{defterm}
- For a code given in encoder-respecting form with maximum graph degree $\Delta$, there is an efficient construction of an encoding circuit of depth at most $2\Delta+3$  ([arXiv:2411.14448](https://arxiv.org/abs/2411.14448)).
- Circuits obtained by first constructing the CWS form of the code  ([arXiv:0803.3232](https://arxiv.org/abs/0803.3232), [arXiv:0708.1021](https://arxiv.org/abs/0708.1021)). These consist of $n$ Hadamard gates, a classical encoder which takes at most $n$ CX gates for a single-qubit encoding code, and at most $n(n-1)/2$ CZ gates to create the needed graph state.
- Lindbladian-based dissipative encoding  ([arXiv:quant-ph/9707049](https://arxiv.org/abs/quant-ph/9707049), [arXiv:1310.1036](https://arxiv.org/abs/1310.1036)), for which the codespace is the steady-state space of a Lindbladian. This does not give a speedup, in terms of scaling with $n$, over circuit-based encoders  ([arXiv:1310.1037](https://arxiv.org/abs/1310.1037)). A finite-time non-Lindbladian dissipative encoder may always be constructed  ([arXiv:2102.04531](https://arxiv.org/abs/2102.04531)).
- Algorithm for fault-tolerant magic-state initialization  ([arXiv:2501.10291](https://arxiv.org/abs/2501.10291)).
- Measurement-based purification protocol yielding arbitrary logical states from initial thermal states  ([arXiv:2502.01393](https://arxiv.org/abs/2502.01393)).
- State injection protocols that generalize lattice surgery for the surface code  ([arXiv:2505.10403](https://arxiv.org/abs/2505.10403)).
- The overlap with any state prepared by a depth-$h$ Clifford circuit with a product state is at most $2^{1-d/2^h}$  ([arXiv:2405.01332](https://arxiv.org/abs/2405.01332)).

## Transversal gates

- Logical Pauli transformations  ([arXiv:quant-ph/9705052](https://arxiv.org/abs/quant-ph/9705052), [arXiv:0903.5256](https://arxiv.org/abs/0903.5256), [arXiv:1803.06987](https://arxiv.org/abs/1803.06987)).
- The four-block transversal gate mapping each $X \to IXXX$ and each $Z \to IZZZ$ implements the same logical gate on all qubits  ([arXiv:quant-ph/9703048](https://arxiv.org/abs/quant-ph/9703048)) ([arXiv:quant-ph/9705052](https://arxiv.org/abs/quant-ph/9705052)). More generally, in the $t$-block setting, the commutant of the $t$-fold action of the $n$-qubit Clifford group contains invertible operators realizing the stochastic orthogonal group $O_t(2)$, yielding inter-block symmetries in tensor powers of stabilizer constructions  ([arXiv:1712.08628](https://arxiv.org/abs/1712.08628)).
- Transversal logical gates are in a finite level of the \term{Clifford hierarchy}, which is shown using stabilizer *disjointness*  ([arXiv:1710.07256](https://arxiv.org/abs/1710.07256)) (see also  ([arXiv:0706.1382](https://arxiv.org/abs/0706.1382), [arXiv:1409.8320](https://arxiv.org/abs/1409.8320))).
Transversal gates for $n\in\{1,2\}$ are semi-Clifford  ([arXiv:0712.2084](https://arxiv.org/abs/0712.2084)).
- No stabilizer code can implement a classical universal gate set transversally  ([arXiv:1704.07798](https://arxiv.org/abs/1704.07798)).
- Fold-transversal gates have been extended from qubit CSS codes to qubit stabilizer codes, and there is an algorithm to determine them from the stabilizer group  ([arXiv:2409.18175](https://arxiv.org/abs/2409.18175)).
- Computation can be sped up substantially for codes that admit transversal measurements of logical $X$ and $Z$  ([arXiv:1210.4626](https://arxiv.org/abs/1210.4626)).
- Diagonal transversal Clifford gates on multiple code blocks must form one of six families of matrix groups: $O(\ell,\mathbb{F}_2)$ generically, $U(\ell,\mathbb{F}_4)$ for Hermitian qubit codes, $GL(\ell,\mathbb{F}_2)$ for non-self-dual CSS codes, $O( \ell, \mathbb{F}_2[x]/(x^2) )$ for self-dual non-CSS codes, $U(\ell,R_8)$ for intermediate semi-self-dual CSS or self-dual semi-CSS cases, and $Sp(2\ell,\mathbb{F}_2)$ for self-dual CSS codes  ([arXiv:2507.10519](https://arxiv.org/abs/2507.10519)). There are two $⟦8,1,3⟧$ self-dual non-CSS codes; see QECDB .
- An entangling diagonal transversal two-qubit Clifford gate exists only for codes equivalent to CSS or self-dual codes; canonical representatives are the inter-block CNOT in the CSS case and a $Y$-controlled-$Y$ gate, locally Clifford equivalent to $CZ$, in the self-dual case  ([arXiv:2507.10519](https://arxiv.org/abs/2507.10519)).
- Implementing the full Clifford group on $k$ logical qubits requires $k$-fold transversal gates; in particular, stabilizer codes cannot admit a transversal (1-fold) implementation of the full Clifford group on more than one logical qubit, a fold-transversal (2-fold) implementation on more than two logical qubits, or a code-automorphism implementation on more than one logical qubit  ([arXiv:2602.13395](https://arxiv.org/abs/2602.13395)). These bounds are tight: $k$ copies of the $⟦7,1,3⟧$ Steane code form a $⟦7k,k,3⟧$ code admitting a $k$-fold transversal Clifford group  ([arXiv:2602.13395](https://arxiv.org/abs/2602.13395)).

## General gates

- Logical Clifford gates can be performed by physical Clifford circuits that permute logical Pauli operators  ([arXiv:1803.06987](https://arxiv.org/abs/1803.06987)).
- With pieceable fault-tolerance, any non-degenerate stabilizer code with a complete set of fault-tolerant single-qubit gates in the Clifford group has a universal set of non-transversal fault-tolerant gates  ([arXiv:1603.03948](https://arxiv.org/abs/1603.03948)).
- Non-Clifford gates can be done using *gate teleportation*, in which a gate can be obtained from a particular *magic state* (a.k.a. resource state)  ([arXiv:quant-ph/9908010](https://arxiv.org/abs/quant-ph/9908010), [arXiv:quant-ph/0002039](https://arxiv.org/abs/quant-ph/0002039)). Such protocols can be made fault tolerant with the help of magic-state distillation  ([arXiv:quant-ph/0403025](https://arxiv.org/abs/quant-ph/0403025)) as well as state-injection and purification schemes based on concatenated error-detecting codes  ([arXiv:quant-ph/0410199](https://arxiv.org/abs/quant-ph/0410199)). There exist various performance metrics for magic-state distillation  ([arXiv:quant-ph/9806094](https://arxiv.org/abs/quant-ph/9806094), [arXiv:1807.10296](https://arxiv.org/abs/1807.10296), [arXiv:1901.03322](https://arxiv.org/abs/1901.03322), [arXiv:1904.01124](https://arxiv.org/abs/1904.01124)) focusing mostly on distilling $T$ gates. This Clifford+T gate set is self-testable  ([arXiv:quant-ph/9904108](https://arxiv.org/abs/quant-ph/9904108)). Gate errors in magic-state distillation protocols can sometimes add up destructively  ([arXiv:1612.01011](https://arxiv.org/abs/1612.01011)). The Hadamard gate cannot be obtained from a magic state  ([arXiv:2312.03515](https://arxiv.org/abs/2312.03515)). A magic state arising from a generalized controlled $Z$ gate is a type of hypergraph state  ([arXiv:1211.5554](https://arxiv.org/abs/1211.5554), [arXiv:1404.6492](https://arxiv.org/abs/1404.6492), [arXiv:1410.3904](https://arxiv.org/abs/1410.3904)) (see  ([arXiv:2310.16982](https://arxiv.org/abs/2310.16982), [arXiv:2404.19005](https://arxiv.org/abs/2404.19005))). The Toffoli gate can be distilled from a particular two-qubit state  ([arXiv:quant-ph/9905027](https://arxiv.org/abs/quant-ph/9905027)). Magic-state protocol fidelity is upper bounded by the fidelity of protocols that have undergone stabilizer reduction, and there exist non-distillable states outside of the stabilizer octahedron  ([arXiv:0908.0836](https://arxiv.org/abs/0908.0836), [arXiv:0908.0838](https://arxiv.org/abs/0908.0838)).
- Certain operations can be implemented in a fault-tolerant version  ([arXiv:0806.0875](https://arxiv.org/abs/0806.0875), [arXiv:0812.4682](https://arxiv.org/abs/0812.4682), [arXiv:0904.2143](https://arxiv.org/abs/0904.2143), [arXiv:1312.0165](https://arxiv.org/abs/1312.0165)) of holonomic quantum computation  ([arXiv:quant-ph/9904011](https://arxiv.org/abs/quant-ph/9904011)).
- Magic-state distillation and circuit compilation based on the SWAP test  ([arXiv:1403.5280](https://arxiv.org/abs/1403.5280)).
- Logical Clifford synthesis (LCS) taking in a code and a logical Clifford operation and producing a circuit acting on the physical qubits  ([arXiv:1907.00310](https://arxiv.org/abs/1907.00310)).
- Clifford stabilizer circuits can be compiled using stabilizer tableau manipulation  ([arXiv:2404.19408](https://arxiv.org/abs/2404.19408)).
- A teleported version of the CPC construction, the Clifford noise reduction (CliNR) scheme, can reduce noise in Clifford circuits with Pauli measurements with at most a three-fold overhead in the number of qubits and gates  ([arXiv:2407.06583](https://arxiv.org/abs/2407.06583), [arXiv:2504.13356](https://arxiv.org/abs/2504.13356)). There is a simple formula for the probability that a Clifford circuit contains a logical error  ([arXiv:2009.07752](https://arxiv.org/abs/2009.07752)).
- Logical Trotter circuits for any stabilizer code can be implemented via symplectic transvections  ([arXiv:2504.11444](https://arxiv.org/abs/2504.11444)).
- Hardware-tailored logical Clifford circuits  ([arXiv:2505.20261](https://arxiv.org/abs/2505.20261)).
- The Bravyi-Koenig bound can be generalized to arbitrary qubit stabilizer codes  ([arXiv:2507.16797](https://arxiv.org/abs/2507.16797)).
- Fault-tolerant flag-based non-transversal logical gates  ([arXiv:2510.08402](https://arxiv.org/abs/2510.08402)).

## Decoders

- The size of the circuit extracting the syndrome depends on the weight of its corresponding stabilizer generator. Syndrome extraction circuits can be simulated efficiently using dedicated software (e.g., STIM  ([arXiv:2103.02202](https://arxiv.org/abs/2103.02202))) and there are many general schemes for generating them  ([arXiv:2408.01339](https://arxiv.org/abs/2408.01339)) (see also  ([arXiv:2402.04093](https://arxiv.org/abs/2402.04093))). Noise can be characterized without interrupting syndrome extraction  ([arXiv:1710.03636](https://arxiv.org/abs/1710.03636)). Decoding of qubit stabilizer codes is an approximately optimal strategy for various quantum lights-out (QLO) games that can be played on the codes' encoder-respecting form  ([arXiv:2411.14448](https://arxiv.org/abs/2411.14448)).
- Instead of applying the Pauli recovery from a fault-tolerant syndrome-extraction gadget, one can usually track it classically as a *Pauli frame*; Clifford operations update the frame by conjugation, while measurement-based non-Clifford gadgets must be interpreted relative to the current frame .
- A greedy graph decoder for encoder-respecting forms corrects all recoverable errors for sufficiently sparse graphs, including graphs with girth at least 13 and some lower-girth families with additional spacing constraints  ([arXiv:2411.14448](https://arxiv.org/abs/2411.14448)).
- DiVincenzo-Aliferis syndrome extraction circuits  ([arXiv:quant-ph/0607047](https://arxiv.org/abs/quant-ph/0607047)).
- Greedy syndrome measurement schedule  ([arXiv:2409.14283](https://arxiv.org/abs/2409.14283)).
- Dynamical weight reduction (DWR) scheme in which measurements of smaller-weight Paulis yield the outcome of a larger-weight Pauli via the use of ZX calculus and ancillary qubits  ([arXiv:2410.12527](https://arxiv.org/abs/2410.12527)).
- Ancilla modes can be used for syndrome extraction instead of ancilla qubits  ([arXiv:quant-ph/0511098](https://arxiv.org/abs/quant-ph/0511098)), and using two-component cat codes  ([arXiv:1807.09334](https://arxiv.org/abs/1807.09334)) yields fault-tolerant syndrome extraction circuits.
- Autonomous QEC protocol  ([arXiv:quant-ph/0402017](https://arxiv.org/abs/quant-ph/0402017)).
- MPE decoding, i.e., the process of finding the most likely error, is $NP$-complete in the worst case  ([arXiv:1009.1319](https://arxiv.org/abs/1009.1319)). If the noise model is such that the most likely error is the lowest-weight error, then ML decoding is called *minimum-weight* decoding. Maximum-likelihood (ML) decoding (a.k.a.\ degenerate maximum-likelihood decoding), i.e., the process of finding the most likely error class (up to degeneracy of errors), is $\#P$-complete in the worst case  ([arXiv:1310.3235](https://arxiv.org/abs/1310.3235)). Decoding a random qubit stabilizer code (i.e., the learning stabilizers with noise, or LSN, problem  ([arXiv:2410.18953](https://arxiv.org/abs/2410.18953))) is at least as hard as decoding a random classical code at constant rate  ([arXiv:2509.20697](https://arxiv.org/abs/2509.20697)).
- Incorporating faulty syndrome measurements can be done by performing spacetime decoding, i.e., using data from past rounds for decoding syndromes in any given round. If a decoder does not process syndrome data sufficiently quickly, it can lead to the *backlog problem*  ([arXiv:1302.3428](https://arxiv.org/abs/1302.3428)), slowing down the computation.
- Splitting decoders  ([arXiv:2309.15354](https://arxiv.org/abs/2309.15354)).
- Trellis decoder, which builds a compact representation of the algebraic structure of the normalizer $\mathsf{N(S)}$  ([arXiv:quant-ph/0512041](https://arxiv.org/abs/quant-ph/0512041)).
- Quantum extension of GRAND decoder  ([arXiv:2208.02744](https://arxiv.org/abs/2208.02744)).
- Deep neural-network probabilistic decoder  ([arXiv:1705.09334](https://arxiv.org/abs/1705.09334)).
- Generalized belief propagation (GBP)  ([arXiv:2212.03214](https://arxiv.org/abs/2212.03214)) based on a classical version .
- Integer optimization decoder  ([arXiv:2008.10206](https://arxiv.org/abs/2008.10206)).
- Autonomous Lindbladian based decoders for codes encoding a single logical qubit  ([arXiv:2308.16233](https://arxiv.org/abs/2308.16233)).
- For codes encoding a single logical qubit, logical information can be extracted by single-qubit operations and classical communication  ([arXiv:2308.14054](https://arxiv.org/abs/2308.14054)).
- Correlated decoding can improve performance of Clifford and non-Clifford entangling gates  ([arXiv:2403.03272](https://arxiv.org/abs/2403.03272)).
- Detector graphs  ([arXiv:2103.02202](https://arxiv.org/abs/2103.02202), [arXiv:2303.15933](https://arxiv.org/abs/2303.15933)) and detector error models  ([arXiv:2407.13826](https://arxiv.org/abs/2407.13826)) can be used to design syndrome extraction circuits and logical measurements.
- Fault-tolerant constant-depth unencoder transforming logical states into physical states using single-qubit measurements  ([arXiv:2408.06299](https://arxiv.org/abs/2408.06299)).
- Degenerate erasure decoder showing near ML decoding for various codes  ([arXiv:2411.13509](https://arxiv.org/abs/2411.13509)).
- Tensor-network decoder for non-Markovian noise  ([arXiv:2412.13739](https://arxiv.org/abs/2412.13739)).
- Delayed-erasure conversion decoder  ([arXiv:2502.20558](https://arxiv.org/abs/2502.20558)).
- Trickle-down dissipative correction  ([arXiv:2507.12534](https://arxiv.org/abs/2507.12534)).

## Fault tolerance

- Shor error correction  ([arXiv:quant-ph/9605011](https://arxiv.org/abs/quant-ph/9605011), [arXiv:quant-ph/9605031](https://arxiv.org/abs/quant-ph/9605031)) (see also Steane's ancilla factory  ([arXiv:quant-ph/9708021](https://arxiv.org/abs/quant-ph/9708021))), in which fault tolerance against syndrome extraction errors is ensured by simply repeating syndrome measurements. A modification uses adaptive measurements  ([arXiv:2208.05601](https://arxiv.org/abs/2208.05601)).
- Gates in the \term{Clifford hierarchy} can be done using *gate teleportation*, in which a gate can be obtained from a particular *magic state*  ([arXiv:quant-ph/9908010](https://arxiv.org/abs/quant-ph/9908010), [arXiv:quant-ph/0002039](https://arxiv.org/abs/quant-ph/0002039)). Such protocols can be made fault tolerant with the help of magic-state distillation  ([arXiv:quant-ph/0403025](https://arxiv.org/abs/quant-ph/0403025)). See review on magic-state distillation  ([doi:10.1002/qua.24856](https://doi.org/10.1002/qua.24856)).
- Logical Bell measurements can be done transversally, and thus fault tolerantly, by performing bitwise Bell measurements for each pair of qubits (with each member of the pair taken from one of the two code blocks) and processing the result.
- With pieceable fault-tolerance, any non-degenerate stabilizer code with a complete set of fault-tolerant single-qubit gates in the Clifford group has a universal set of non-transversal fault-tolerant gates  ([arXiv:1603.03948](https://arxiv.org/abs/1603.03948)).
- Generalization of Steane error correction for stabilizer codes .
- Fault-tolerant error correction scheme by Knill (a.k.a. telecorrection  ([arXiv:quant-ph/0601066](https://arxiv.org/abs/quant-ph/0601066))), which is based on teleportation  ([arXiv:quant-ph/0410199](https://arxiv.org/abs/quant-ph/0410199), [arXiv:quant-ph/0312190](https://arxiv.org/abs/quant-ph/0312190)). A variant of it has been termed the Fibonacci scheme  ([arXiv:0809.5063](https://arxiv.org/abs/0809.5063)).
- For a non-CSS stabilizer code, the logical Bell-state ancilla needed for Knill error correction can be prepared by treating two code blocks as one larger stabilizer state and verifying the combined stabilizer via the Shor-style preparation procedure .
- Fault-tolerant error correction using flag qubits for codes satisfying certain conditions  ([arXiv:1708.02246](https://arxiv.org/abs/1708.02246)).
- GHZ state distillation for Steane error correction  ([arXiv:2109.06248](https://arxiv.org/abs/2109.06248)).
- Syndrome extraction using flag qubits and classical codes  ([arXiv:2212.10738](https://arxiv.org/abs/2212.10738)).
- Fault-tolerant constant-depth unencoder transforming logical states into physical states using single-qubit measurements  ([arXiv:2408.06299](https://arxiv.org/abs/2408.06299)).
- Post-selection based algorithm preparing magic state corresponding to arbitrary rotations  ([arXiv:2303.17380](https://arxiv.org/abs/2303.17380)).
- Code switching can be done using only transversal gates for qubit stabilizer codes  ([arXiv:2409.13465](https://arxiv.org/abs/2409.13465)).
- Flag-Proxy Networks (FPNs)  ([arXiv:2409.14283](https://arxiv.org/abs/2409.14283)).
- A logical Pauli can be gauged out to yield a fault-tolerant measurement with worst-case qubit overhead $O(W\log^{2}W)$ for a weight-$W$ Pauli  ([arXiv:2410.02213](https://arxiv.org/abs/2410.02213)).
- Automated fault-tolerant circuit synthesis using boolean satisfiability  ([arXiv:2501.05527](https://arxiv.org/abs/2501.05527)).
- Algorithm for fault-tolerant magic-state initialization  ([arXiv:2501.10291](https://arxiv.org/abs/2501.10291)).
- Fault tolerance of qubit stabilizer codes has been formalized  ([arXiv:2501.14380](https://arxiv.org/abs/2501.14380)).
- Fault-tolerant flag-based non-transversal logical gates  ([arXiv:2510.08402](https://arxiv.org/abs/2510.08402)).

## Relations

- _parent_: [[concepts/qec/non-stabilizer]] — A stabilizer code with stabilizer group $\mathsf{S}$ can be thought of as a USt with only the identity coset representative.
Conversely, if the set of coset representatives of a USt form a linear binary code, then they can be absorbed into a stabilizer group that defines the USt.
- _parent_: [[concepts/qec/xp-stabilizer]] — XP stabilizer codes reduce to qubit stabilizer codes for $N=2$.
- _parent_: [[concepts/qec/qubit-stabilizer-oaqecc]] — An OA qubit stabilizer code storing no classical information and admitting no gauge qubits is a qubit stabilizer code.
- _parent_: [[concepts/qec/qudit-stabilizer]] — Modular-qudit stabilizer codes for $q=2$ correspond to qubit stabilizer codes.
Modular-qudit stabilizer codes for prime-dimensional qudits $q=p$ inherit most of the features of qubit stabilizer codes, including encoding an integer number of qudits and a modular-qudit Pauli group with a unique number of generators.
Conversely, qubit codes can be extended to modular-qudit codes by decorating appropriate generators with powers.
For example, $⟦4,2,2⟧$ qubit code generators can be adjusted to $ZZZZ$ and $XX^{-1} XX^{-1}$.
A systematic procedure extending a qubit code to prime-qudit codes involves putting its generator matrix into local-dimension-invariant (LDI) form   ([arXiv:1910.08122](https://arxiv.org/abs/1910.08122)).
Various bounds exist on the distance of the resulting codes  ([arXiv:2110.11510](https://arxiv.org/abs/2110.11510), [arXiv:2110.15274](https://arxiv.org/abs/2110.15274)).
- _parent_: [[concepts/qec/galois-true-stabilizer]] — True Galois-qudit stabilizer codes for $q=2$ correspond to qubit stabilizer codes.
- _cousin_: [[concepts/qec/cws]] — CWS codes whose underlying classical code is a linear binary code are qubit stabilizer codes containing a cluster-state codeword  ([arXiv:0708.1021](https://arxiv.org/abs/0708.1021), [arXiv:1407.2777](https://arxiv.org/abs/1407.2777)).
Conversely, stabilizer codes admit a CWS standard form  ([arXiv:0708.1021](https://arxiv.org/abs/0708.1021)); at the state level, the underlying stabilizer state can be mapped to a cluster state by a single-qubit Clifford circuit  ([arXiv:quant-ph/0308151](https://arxiv.org/abs/quant-ph/0308151)) ([arXiv:1910.00471](https://arxiv.org/abs/1910.00471)).
- _cousin_: [`binary_linear`](https://errorcorrectionzoo.org/c/binary_linear) — Qubit stabilizer codes are the closest quantum analogues of binary linear codes because addition modulo two corresponds to multiplication of stabilizers in the quantum case. 
Any binary linear code can be thought of as a qubit stabilizer code with $Z$-type stabilizer generators  ([arXiv:quant-ph/0610088](https://arxiv.org/abs/quant-ph/0610088)) ([arXiv:2507.05408](https://arxiv.org/abs/2507.05408)). 
The stabilizer generators are extracted from rows of the parity-check matrix, while logical $X$ Paulis correspond to rows of the generator matrix.
States close to the equal superposition of all bitstrings within Hamming distance $b$ of a binary linear code can be prepared efficiently  ([arXiv:2404.16129](https://arxiv.org/abs/2404.16129)).
Binary linear codes can be used for error-corrected entanglement distillation protocols  ([arXiv:2408.06299](https://arxiv.org/abs/2408.06299)).
- _cousin_: [`dual`](https://errorcorrectionzoo.org/c/dual) — Qubit stabilizer codes are in one-to-one correspondence with symplectic self-orthogonal binary linear codes of length $2n$ via the symplectic representation.
- _cousin_: [`dual_additive`](https://errorcorrectionzoo.org/c/dual_additive) — Qubit stabilizer codes are in one-to-one correspondence with trace-Hermitian self-orthogonal additive quaternary codes of length $n$ via the $\mathbb{F_4$ representation}.
- _cousin_: [[concepts/qec/single-shot]] — Any stabilizer code can be single shot if sufficiently non-local high-weight stabilizer generators are used for syndrome measurements.  These can be obtained with a Gaussian elimination procedure  ([arXiv:1805.09271](https://arxiv.org/abs/1805.09271)).
- _cousin_: [`t-designs`](https://errorcorrectionzoo.org/c/t-designs) — Stabilizer states on $n$ qubits form complex projective 3-designs, but not 4-designs, on $\mathbb{C}P^{2^n-1}$  ([arXiv:1510.02767](https://arxiv.org/abs/1510.02767)). The Clifford group is a unitary 2-design  ([arXiv:quant-ph/0103098](https://arxiv.org/abs/quant-ph/0103098)) and a 3-design  ([arXiv:math/0502080](https://arxiv.org/abs/math/0502080)) ([doi:10.1007/3-540-30731-1](https://doi.org/10.1007/3-540-30731-1)) ([arXiv:1510.02619](https://arxiv.org/abs/1510.02619), [arXiv:1510.02769](https://arxiv.org/abs/1510.02769)) on $U(2^n)$. The $⟦2m,2m-2,2⟧$ code for $2m$ being a multiple of four obstructs the Clifford group from being a 4-design  ([arXiv:1609.08172](https://arxiv.org/abs/1609.08172)).
- _cousin_: [`unitary_design`](https://errorcorrectionzoo.org/c/unitary_design) — Stabilizer states on $n$ qubits form complex projective 3-designs, but not 4-designs, on $\mathbb{C}P^{2^n-1}$  ([arXiv:1510.02767](https://arxiv.org/abs/1510.02767)). The Clifford group is a unitary 2-design  ([arXiv:quant-ph/0103098](https://arxiv.org/abs/quant-ph/0103098)) and a 3-design  ([arXiv:math/0502080](https://arxiv.org/abs/math/0502080)) ([doi:10.1007/3-540-30731-1](https://doi.org/10.1007/3-540-30731-1)) ([arXiv:1510.02619](https://arxiv.org/abs/1510.02619), [arXiv:1510.02769](https://arxiv.org/abs/1510.02769)) on $U(2^n)$. The $⟦2m,2m-2,2⟧$ code for $2m$ being a multiple of four obstructs the Clifford group from being a 4-design  ([arXiv:1609.08172](https://arxiv.org/abs/1609.08172)).
- _cousin_: [`complex_projective`](https://errorcorrectionzoo.org/c/complex_projective) — Stabilizer states on $n$ qubits form complex projective 3-designs, but not 4-designs, on $\mathbb{C}P^{2^n-1}$  ([arXiv:1510.02767](https://arxiv.org/abs/1510.02767)). The Clifford group is a unitary 2-design  ([arXiv:quant-ph/0103098](https://arxiv.org/abs/quant-ph/0103098)) and a 3-design  ([arXiv:math/0502080](https://arxiv.org/abs/math/0502080)) ([doi:10.1007/3-540-30731-1](https://doi.org/10.1007/3-540-30731-1)) ([arXiv:1510.02619](https://arxiv.org/abs/1510.02619), [arXiv:1510.02769](https://arxiv.org/abs/1510.02769)) on $U(2^n)$.
- _cousin_: [[concepts/qec/iceberg]] — The $⟦2m,2m-2,2⟧$ code for $2m$ being a multiple of four obstructs the Clifford group from being a 4-design  ([arXiv:1609.08172](https://arxiv.org/abs/1609.08172)).
- _cousin_: [[concepts/qec/ampdamp]] — Concatenating the dual-rail code with an inner $⟦n,k,d⟧$ qubit stabilizer code yields a degenerate $⟦2n,k,d⟧$ constant-excitation stabilizer code that corrects $d-1$ AD errors  ([arXiv:1001.2356](https://arxiv.org/abs/1001.2356), [arXiv:2010.00538](https://arxiv.org/abs/2010.00538)).
- _cousin_: [[concepts/qec/two-legged-cat]] — Ancilla modes can be used for syndrome extraction instead of ancilla qubits  ([arXiv:quant-ph/0511098](https://arxiv.org/abs/quant-ph/0511098)), and using two-component cat codes  ([arXiv:1807.09334](https://arxiv.org/abs/1807.09334)) yields fault-tolerant syndrome extraction circuits.
- _cousin_: [`projective`](https://errorcorrectionzoo.org/c/projective) — $⟦n,k,d⟧$ qubit stabilizer codes with no weight-one stabilizers are equivalent to particular "quantum" sets of lines in projective space $PG(n-k-1,2)$  ([arXiv:2007.05992](https://arxiv.org/abs/2007.05992)) ([arXiv:2107.11281](https://arxiv.org/abs/2107.11281)). - _cousin_: [[concepts/qec/holographic]] — Qubit stabilizer states can be interpreted as states that are preparable using the Euclidean path integral in 3D Chern-Simons theory, defined on manifolds that are toy models of AdS/CFT wormholes  ([arXiv:1611.01516](https://arxiv.org/abs/1611.01516), [arXiv:2510.15067](https://arxiv.org/abs/2510.15067)).
- _cousin_: [[concepts/qec/topological-abelian]] — Qubit stabilizer states can be interpreted as states that are preparable using the Euclidean path integral in 3D Chern-Simons theory, defined on manifolds that are toy models of AdS/CFT wormholes  ([arXiv:1611.01516](https://arxiv.org/abs/1611.01516), [arXiv:2510.15067](https://arxiv.org/abs/2510.15067)).
- _cousin_: [[concepts/qec/galois-css]] — Any $⟦n,k,d⟧$ qubit stabilizer code can be mapped to an $⟦n,k,d⟧_4$ Galois-qudit CSS code via the BLT mapping  ([arXiv:2605.15344](https://arxiv.org/abs/2605.15344)) ([arXiv:1004.3791](https://arxiv.org/abs/1004.3791)): each stabilizer $P = \bigotimes_j P_j$ generates an $XX$-type stabilizer via $\mathcal{D}_X$ ($I\mapsto II,\,X\mapsto XI,\,Z\mapsto IX,\,Y\mapsto XX$) and a $ZZ$-type stabilizer via $\mathcal{D}_Z$ ($I\mapsto II,\,X\mapsto IZ,\,Z\mapsto ZI,\,Y\mapsto ZZ$).
